## 详细总结

### 1. 研究背景与问题提出

高熵合金，尤其是以 `Nb`、`Ti`、`V`、`Zr` 等高熔点元素为基础的难熔高熵合金（`RHEAs`），因其高温强度、耐磨性和结构稳定性而受到关注。`Al-Nb-Ti-V-Zr` 体系兼具轻量化潜力与较高强度，但 `Al` 的作用较为复杂。一方面，`Al` 可以降低密度并通过固溶强化或强化相形成提升强度；另一方面，`Al` 与 `Zr` 之间较强的化学亲和力又可能促进脆性金属间化合物或 `Laves` 相形成，从而损害塑性。论文的核心问题因此集中在：在同一五元体系与同一 `BCC` 基本结构框架下，同时降低 `Al` 与 `Zr` 含量，会如何改变局域晶格畸变、弹性各向异性、拉伸变形响应以及原子尺度局域结构演化。

作者指出，传统经验势，尤其是主要针对单元或二元体系开发的 `EAM` 势，通常难以准确描述高熵合金中复杂的多元化学环境、严重的局域晶格畸变以及可能存在的无序 - 有序竞争。这会直接影响对相稳定性、弹性性质与缺陷能学的预测可靠性。因此，论文从方法学上试图证明：面向 `Al-Nb-Ti-V-Zr` 五元体系训练的深度学习势（`DLP`），能否在保持接近 `DFT` 精度的同时，支撑更大尺度的分子动力学拉伸模拟。

### 2. 研究目标

本文有两个并行目标：

1. 构建并验证一个适用于 `Al-Nb-Ti-V-Zr` 五元难熔高熵合金体系的 `DLP`；
2. 用该势系统比较等原子比 `AlNbTiVZr` 与非等原子比 `Al0.5NbTiVZr0.5` 在局域结构、弹性性质、拉伸强度与原子体积统计上的差异。

作者选择这两个成分并非任意，而是因为已有实验与 `DFT` 研究都把它们视为分析强度 - 延性权衡的重要对照组。`AlNbTiVZr` 是该轻质 `RHEA` 家族中广泛研究的基准成分，而 `Al0.5NbTiVZr0.5` 则已被报道具有更优的力学响应与更有利的强塑平衡。

### 3. 训练数据集与深度学习势构建

作者基于 `DFT` 与 `DP-GEN` 式并发学习流程，构建了覆盖体相、表面、应变态、广义层错、二聚体与主动学习补充结构的训练数据集，总计 `2373` 个已标注构型。数据组成包括：

- `367` 个体相高熵合金超胞；
- `401` 个表面高熵合金超胞；
- `68` 个参考体相结构；
- `58` 个应变 / 缩放结构；
- `86` 个广义层错结构；
- `240` 个二聚体构型；
- `1153` 个并发学习补充标注结构。

`DFT` 计算采用 `Quantum ESPRESSO`，交换关联泛函为 `PBE`，并使用 `SSSP efficiency v1.3.0` 赝势。并发学习阶段在 `LAMMPS` 中进行 `NPT` 采样，温度从 `100 K` 升至 `300 K`，持续 `500 ps`，再由 `DFT` 回标。作者用这些数据训练 `DeepMD` 势，局域描述符为 `se_a`，截断半径 `8.5 Å`，平滑半径 `2.77 Å`，嵌入网络为 `{25, 50, 100}`，拟合网络为 `{240, 240, 240}`，共独立训练 `4` 个初始化不同的模型。

训练分两阶段进行：标注相关训练 `5 × 10^5` 步，最终训练 `2.5 × 10^6` 步。损失函数权重从强调力拟合逐步转向兼顾能量与维里量，这意味着模型训练策略是先稳定学习局域原子受力，再逐步提高整体能量一致性。

### 4. 初始结构生成与模拟方法

两种成分的初始 `BCC` 结构均由 `MaxEnt MC` 算法生成。作者强调，这并非简单的随机占位，而是通过 `100,000` 次蒙特卡罗原子交换，促进最近邻壳层内的化学异质混合，从而抑制有限尺寸模型中的虚假短程同类聚集。也就是说，初始构型更接近“高构型熵、强化学混合”的无序固溶体状态。

后续模拟分两类：

- 弹性常数计算使用 `1024` 原子超胞；
- 单轴拉伸模拟使用 `13,500` 原子大超胞。

弹性张量在 `0 K` 下通过有限应变法得到；多晶体模量 `B`、`G`、`E` 通过 `ElasticPOST` 软件基于 `Voigt-Reuss-Hill` 近似计算。单轴拉伸沿 `z` 方向施加，应变率为 `2 × 10^8 s^-1`，即每 `5 ps` 增加 `0.001` 的工程应变，在 `300 K`、`NPT` 系综下进行，同时保持横向 `x` 与 `y` 方向压力为 `0 kbar`。作者用 `OVITO` 中的 `PTM` 方法把局域结构分类为 `BCC`、`FCC`、`HCP` 与 `Other`。

### 5. 深度学习势验证结果

`3.1` 节首先证明该 `DLP` 的可用性。对于每原子能量，训练集与验证集上的 `RMSE` 都为 `0.048 eV atom^-1`，`MAE` 为 `0.033 eV atom^-1`，`R^2` 分别为 `0.996` 与 `0.995`。对原子力，训练集与验证集的 `RMSE` 分别为 `0.097` 与 `0.098 eV Å^-1`，`R^2` 分别为 `0.954` 与 `0.953`。对维里量，训练与验证 `RMSE` 分别为 `1.782` 与 `1.755 eV`，`R^2` 分别为 `0.942` 与 `0.927`。

从论文的论证方式看，作者并未把验证局限于点对点误差，而是继续检查：

- 两种合金的能量 - 体积曲线是否能复现平衡体积附近的曲率与极小值位置；
- 广义层错能（`GSFE`）曲线是否能复现与滑移势垒、缺陷形核相关的能量障碍特征。

因此，这一 `DLP` 被视为不仅能拟合离散 `DFT` 标签，还能描述与后续弹性和塑性分析相关的连续体积响应与剪切势垒势能曲面。

### 6. 局域结构与静态晶格畸变

`3.2` 节围绕一个关键问题展开：非等原子比成分为何可能更稳定。作者先用部分径向分布函数（`PRDF`）证明，`MaxEnt MC` 生成的初始结构在最近邻尺度上以异类原子对为主，并没有明显的同类元素团聚。这说明两种模型确实可作为化学无序高熵固溶体的合理原子级近似。

随后，作者把弛豫后相对于理想 `BCC` 晶格位置的原子位移幅值，定义为静态局域晶格畸变的原子尺度度量。结果显示：

- 在 `AlNbTiVZr` 中，`Al`、`Nb`、`Ti`、`V`、`Zr` 的平均位移约为 `0.256`、`0.193`、`0.214`、`0.192`、`0.166 Å`；
- 在 `Al0.5NbTiVZr0.5` 中，相应数值降为约 `0.198`、`0.153`、`0.153`、`0.139`、`0.126 Å`。

这意味着，非等原子比合金中所有元素的位移分布都更窄、平均位移更小，更接近理想 `BCC` 参考晶格。

论文对这一结果的解释很有针对性。作者特别指出，不能仅用“原子半径失配”理解局域弛豫。若仅看原子尺寸，最大的 `Zr` 理应产生最大位移；但实际是 `Al` 的位移最大而 `Zr` 最小。作者据此提出：

- `Al` 的大位移更多来自局域化学环境与电子结构非对称性；
- 在富 `Nb-V-Ti-Zr` 的 `BCC` 基体中，`Al` 会表现出更强的方向性 `Al-p / 过渡金属-d` 相互作用；
- 这种方向敏感成键使 `Al` 容易出现偏心弛豫，而不是简单的各向同性半径失配位移；
- `Zr` 虽然尺寸最大，但更主要通过扩大周围配位壳层、增加局域原子体积来引入畸变，因而“环境体积膨胀很明显，但自身位移并不最大”。

因此，论文将两类局域畸变源区分为：

- `Al` 主导的方向性、化学敏感、偏心型位置畸变；
- `Zr` 主导的尺寸相关、体积膨胀型局域体积畸变。

当同时降低 `Al` 与 `Zr` 含量时，这两类主要畸变源都被削弱，于是 `Al0.5NbTiVZr0.5` 的局域结构更均匀，静态畸变更弱。

### 7. 结构与弹性性质

`3.3` 节表明，两种成分在当前立方 `BCC` 近似下都满足 `Born` 力学稳定性判据，即：

- $C_{11} > 0$
- $C_{44} > 0$
- $C_{11} > C_{12}$
- $C_{11} + 2C_{12} > 0$

但两者弹性刚度存在明显差异。作者给出的“本文计算”结果为：

- `AlNbTiVZr`：晶格常数 `0.328 nm`，$C_{11} = 132.83$ `GPa`，$C_{12} = 108.03$ `GPa`，$C_{44} = 51.02$ `GPa`，$B = 116.30$ `GPa`，$G = 29.14$ `GPa`，$E = 80.70$ `GPa`
- `Al0.5NbTiVZr0.5`：晶格常数 `0.325 nm`，$C_{11} = 151.21$ `GPa`，$C_{12} = 103.72$ `GPa`，$C_{44} = 54.57$ `GPa`，$B = 119.55$ `GPa`，$G = 39.08$ `GPa`，$E = 105.72$ `GPa`

这说明，降低 `Al` 与 `Zr` 含量后：

- 轴向刚度与剪切相关刚度明显提高；
- 体模量仅小幅变化；
- 结构对定向变形与剪切变形的抗力明显增强。

作者还从三维模量曲面分析弹性各向异性。`B` 的方向依赖性很弱，近似球形；而 `E` 与 `G` 曲面均显著偏离球形。等原子比合金的模量曲面起伏更强，非等原子比合金则相对更平缓。对应的 `Zener` 各向异性因子从 `4.11` 降到 `2.30`，说明 `Al0.5NbTiVZr0.5` 虽仍明显各向异性，但比 `AlNbTiVZr` 更接近弹性各向同性极限。

作者把这种差异明确归因于前一节发现的局域畸变差异：等原子比合金内部存在更强的位置弛豫、`Al-Zr` 相关化学环境差异以及非均匀的局域键刚度，因此其宏观弹性响应更依赖方向；而非等原子比合金因局域环境更均匀，故表现出更高的剪切刚度和更低的各向异性。

### 8. 拉伸变形与局域结构演化

`3.4` 节分析 `300 K` 下的单轴拉伸。作者使用 `0.2%` 偏移准则定义屈服强度 `σ_YS` 与屈服应变 `ε_YS`，用应力峰值及对应应变定义极限抗拉强度 `σ_UTS` 与极限应变 `ε_UTS`。两种合金在初始态均以 `BCC` 类局域结构为主；弹性阶段应力近线性增加，且直到屈服点前 `BCC` 分数仍不低于 `94.6%`，说明屈服之前的结构骨架仍基本保持 `BCC` 主导。

进入塑性阶段后，`BCC` 分数开始下降，而 `FCC`、`HCP` 与 `Other` 分数上升，这被作者解释为应变诱导局域结构重排，而非对初始 `BCC` 晶格的纯仿射拉伸。

定量上：

- 初始态 `BCC` 分数：`AlNbTiVZr` 为 `97.9%`，`Al0.5NbTiVZr0.5` 为 `99.9%`
- 屈服点：分别为 `94.6%` 与 `99.0%`
- 中间塑性阶段（`ε = 0.1`）：分别降到 `80.4%` 与 `88.7%`
- 极限抗拉态：分别降到 `37.0%` 与 `61.2%`

力学性能方面：

- `AlNbTiVZr`：$σ_{YS} = 5.529$ `GPa`，$ε_{YS} = 0.046$，$σ_{UTS} = 15.353$ `GPa`，$ε_{UTS} = 0.172$
- `Al0.5NbTiVZr0.5`：$σ_{YS} = 6.621$ `GPa`，$ε_{YS} = 0.049$，$σ_{UTS} = 17.069$ `GPa`，$ε_{UTS} = 0.191$

也就是说，非等原子比合金同时获得了更高的屈服强度、更高的极限强度以及更大的应力峰值对应应变。作者认为，这一改进并不是单纯的“强度更高”，而是其 `BCC` 骨架在更大应变范围内保留得更久，结构退化被推迟了。

作者还特别解释了断裂阶段 `BCC` 分数回升的现象。`AlNbTiVZr` 在极限态后的断裂阶段 `BCC` 分数从 `37.0%` 回升到 `54.4%`，但作者明确指出，这并不表示真正的力学稳定 `BCC` 框架恢复，而更可能是应力卸载与局部碎片化后的几何重新分类效应。相较之下，`Al0.5NbTiVZr0.5` 在达到极限强度之前就一直保持更高比例的 `BCC` 局域有序，因此其“延缓退化”更具物理意义。

### 9. 原子体积统计与局域体积非均匀性

`3.5` 节从原子体积统计角度继续解释两种成分差异。作者比较了未变形态 `ε = 0` 与极限抗拉态 `ε_UTS` 下的原子体积分布，并用：

- `μ` 表示平均原子体积；
- `σ` 表示原子体积分布标准差。

对 `AlNbTiVZr`，`μ` 从约 `17.8` 增至 `20.9 Å^3`，`σ` 从约 `1.0` 增至 `1.9 Å^3`。对 `Al0.5NbTiVZr0.5`，`μ` 从约 `17.2` 增至 `20.5 Å^3`，`σ` 从约 `0.8` 增至 `1.6 Å^3`。两种合金都在拉伸下整体膨胀，但等原子比合金在高载荷状态下产生了更强的微观体积非均匀性。

元素分辨的分布进一步表明：

- 所有元素对应的局域环境在拉伸下都向更大原子体积移动；
- `Zr` 中心环境始终具有最大的平均原子体积与最显著的高体积尾部拓宽；
- `V` 中心环境则始终位于较小体积分支，更为紧凑。

作者据此得出一个很清晰的结论：拉伸引发的体积膨胀并不是化学上均匀分配的，而是明显具有元素依赖性。其中，富 `Zr` 的局域环境更容易承受更大的局部膨胀，因此对高体积尾部和体积非均匀性的累积贡献最大。

当把整个加载过程中的 `μ` 与 `σ` 作为应变函数来跟踪时，可以看到：

- 两种合金的平均原子体积都随应变持续增加；
- 体积分布宽度也随应变增加而增大；
- 但 `Al0.5NbTiVZr0.5` 的初始 `σ` 更小，增长更缓；
- 尤其在高应变阶段，非等原子比合金中 `Zr` 相关分布带的上边界增长明显弱于等原子比合金。

因此，作者把非等原子比合金更优的拉伸表现，进一步归因于其对“局域体积非均匀性累积”的抑制。

### 10. 论文的核心物理图像

整篇论文建立的因果链条可以概括为：

1. 同时降低 `Al` 与 `Zr` 含量，减少了两类主要局域畸变源；
2. `Al` 相关的方向性偏心弛豫减弱，`Zr` 相关的局域体积膨胀也减弱；
3. 初始 `BCC` 基体的局域结构更均匀、静态畸变更小；
4. 宏观上表现为更高的 `C11`、`C44`、`G`、`E` 与更低的 `Zener` 各向异性因子；
5. 拉伸过程中，`BCC` 局域结构退化更慢；
6. 体积非均匀性的积累被抑制，特别是富 `Zr` 高体积局域环境的发展被延缓；
7. 最终体现为更高的屈服强度、更高的极限抗拉强度和更大的极限应变。

### 11. 文章贡献与适用边界

本文最重要的贡献，是将一个经过 `DFT`、能量 - 体积关系和 `GSFE` 趋势共同验证的 `DLP`，真正用于解释 `Al-Nb-Ti-V-Zr` 难熔高熵合金中“成分调整 - 局域畸变 - 弹性各向异性 - 拉伸结构演化 - 体积非均匀性”之间的连续联系。它不仅比较了两种成分的强度差异，还给出了为什么这种差异会在原子尺度上出现的结构性解释。

从论文本身能直接确认的边界看：

- 所有原子尺度结论都建立在本文给定的 `DLP` 训练覆盖范围内；
- 拉伸行为分析仅针对 `300 K`、本文设定的应变率以及两种特定成分；
- 初始结构为 `MaxEnt MC` 构造的 `BCC` 基结构；
- 论文没有把结论外推到其他成分、其他加载模式或显式多相组织。

## 摘要翻译

化学无序的多组元合金，对传统经验型原子间势的可迁移性提出了严格挑战。本文针对五元 `Al-Nb-Ti-V-Zr` 体系，利用 `2373` 个由密度泛函理论标注的构型开发了一种深度学习势（`DLP`）。这些构型覆盖体相、表面、应变态、广义层错、二聚体以及并发学习所选取的结构。验证结果表明，能量的均方根误差为 `0.048 eV atom^-1`，力的均方根误差为 `0.098 eV Å^-1`；同时，该模型还复现了维里响应、能量 - 体积关系以及广义层错能曲线。经过验证的 `DLP` 支持开展 `13500` 原子尺度的分子动力学模拟，用于研究 `300 K` 下等原子比 `AlNbTiVZr` 与非等原子比 `Al0.5NbTiVZr0.5` 的拉伸变形。降低 `Al` 与 `Zr` 含量后，各元素分辨的弛豫位移减小，`Zener` 各向异性因子由 `4.11` 降至 `2.30`，而杨氏模量则由 `80.70` 提高至 `105.72 GPa`。与等原子比合金的 `15.353 GPa` 和 `37.0%` 相比，非等原子比合金表现出更高的极限抗拉强度 `17.069 GPa`，并且在峰值应力处仍保留 `61.2%` 的体心立方（`BCC`）类局域环境。原子体积统计还表明，拉伸载荷会放大化学上异质的局域膨胀，其中以 `Zr` 为中心的局域环境对高体积尾部的贡献最为显著。这些结果说明，该 `DLP` 能够在直接第一性原理模拟难以达到的尺度上，解析成分依赖的晶格畸变、弹性各向异性以及变形诱导的结构演化，并为研究所采样成分与变形空间内的 `Al-Nb-Ti-V-Zr` 难熔高熵合金提供了经过验证的框架。

## 引言翻译

高熵合金（`HEAs`）由 `5` 种或更多主元素以近等原子比组成，它通过挑战传统合金设计理念，已成为现代物理冶金中的一个重要合金设计概念 [1]。在各类 `HEA` 中，以高熔点元素（例如 `Nb`、`Mo`、`Ta`、`W`、`Ti`、`V`、`Zr`）为基础的难熔高熵合金（`RHEAs`），正被积极研究用于高温结构应用，例如航空航天和发电工业 [2, 3]。

这类合金通常表现出相对简单的 `BCC` 或 `FCC` 固溶体结构，而这通常与多组元体系较高的构型熵有关 [4]。这种独特的结构特征，再加上严重的晶格畸变和迟滞扩散，使 `RHEAs` 具备优异的性能，包括高温强度、耐磨性和结构稳定性 [5, 6]。在所有 `RHEAs` 中，`Al-Nb-Ti-V-Zr` 体系作为一种轻质体系尤其具有前景，其密度低于传统镍基高温合金或钨基 `RHEAs` [7]。加入铝（`Al`）能够进一步降低密度，并可能通过固溶强化与强化相形成来提升强度 [8, 9]。然而，基于现有实验和理论方法，`Al` 的作用仍不清晰；它在某些体系中可以稳定 `BCC` 固溶体，但在更高浓度或特定热处理后，也已知会促进金属间化合物相的形成，例如 `Laves` 相（如 `C14 ZrAlV` 型）[10]。`Al` 与 `Zr` 之间很强的化学亲和力，以高度负的混合焓为特征，往往会驱动这些金属间化合物形成，并显著影响力学性能 [10, 11]。要在该体系中实现理想的强度 - 延性平衡，需要对成分进行精细控制，以调节韧性 `BCC` 基体与潜在脆性第二相之间的相互作用 [12]。

分子动力学（`MD`）模拟被广泛用于研究 `HEAs` 中与成分相关的行为和原子尺度变形机制。然而，`MD` 模拟的准确性高度依赖于原子间势的质量。传统势函数，例如基于嵌入原子法（`EAM`）的势，往往是为单元或二元体系开发的，难以准确描述 `HEAs` 固有的复杂多元素化学环境和严重晶格畸变 [13]。这种局限常常导致对相稳定性、弹性性质以及缺陷能学的预测不准确，从而削弱对力学行为模拟的可靠性。

机器学习原子间势，例如在 `DeepMD-kit` 中实现的深度学习势（`DLP`）模型，为解决这一挑战提供了实用途径 [14, 15]。通过使用来源于密度泛函理论（`DFT`）计算的能量、力和维里数据训练深度神经网络，`DLP` 可以在远低于直接 `DFT` 计算的成本下复现选定的参考性质，从而支持更大尺度的 `MD` 模拟 [16]。因此，这种方法非常适合在不依赖预设解析形式的情况下，模拟多主元合金复杂的势能曲面 [17]。

本文为五元 `Al-Nb-Ti-V-Zr` 体系开发并验证了一种 `DLP`，并用其研究两个具有代表性的成分，即等原子比 `AlNbTiVZr` 与非等原子比 `Al0.5NbTiVZr0.5`。之所以选择这两种合金，是因为近期针对 `AlNbTiVZr` 系列的实验与 `DFT` 研究已将它们视为考察强度 - 延性权衡的一组有意义成分。等原子比 `AlNbTiVZr` 是这一轻质难熔 `HEA` 家族中被广泛研究的基准成分，而已有报道指出，`Al0.5NbTiVZr0.5` 具有更有利的力学响应，包括更优的强塑平衡以及在均匀化处理后的脆 - 韧转变。既有研究还表明，降低 `Al` 含量本身有助于提升延性，而与 `Al` 和 `Zr` 相关的原子相互作用则会促进脆性金属间相或 `Laves` 型相形成，从而损害延性。因此，本文选择 `AlNbTiVZr` 与 `Al0.5NbTiVZr0.5` 作为一组成分可控的对照，以考察在保持相同五元合金体系和 `BCC` 基结构框架的条件下，同时降低 `Al` 与 `Zr` 含量将如何改变局域畸变、结构稳定性与拉伸变形行为。通过比较这两种成分，本文旨在阐明成分如何影响力学响应，并评估当前 `DLP` 框架在 `Al-Nb-Ti-V-Zr` 难熔高熵合金原子尺度研究中的适用性。

## 方法翻译

### 2. 计算方法

#### 2.1 第一性原理数据生成

用于训练本文 `DLP` 的参考数据集来源于基于 `DFT` 的第一性原理计算，并进一步通过 `DP-GEN` 类型的并发学习流程进行扩展 [18]。所有 `DFT` 计算均采用 `Quantum ESPRESSO`（`QE`）软件包 [19]，交换关联泛函使用 `Perdew-Burke-Ernzerhof`（`PBE`）广义梯度近似 [20]。表 `1` 总结了生成参考标签时所采用的 `DFT` 设置。补充材料中的表 `S1-S4` 对数据集组成与扩展流程给出了详细说明。如表 `S1` 所列，最终的 `DFT` 标注数据集总共包含 `2373` 个构型，其中包括 `367` 个体相高熵合金超胞、`401` 个表面高熵合金超胞、`68` 个参考体相结构、`58` 个应变 / 缩放结构、`86` 个广义层错结构、`240` 个二聚体构型以及 `1153` 个目标标注结构。

表 `S2` 和表 `S3` 进一步给出了这些高熵合金超胞在结构与成分上的具体特征。`367` 个体相高熵合金结构包括 `5` 个四元等原子比 `BCC` 超胞，以及 `362` 个覆盖等原子比和非等原子比组成的五元 `Al-Nb-Ti-V-Zr` 超胞。在五元体相数据集中，`Al`、`Ti`、`V` 和 `Zr` 的含量范围为 `5.6-53.1 at.%`，而 `Nb` 的含量范围为 `8.3-28.1 at.%`。这些体相结构覆盖了 `FCC`（`153` 个）、`BCC`（`106` 个）和 `HCP`（`103` 个）晶格；其中 `FCC/HCP` 超胞为 `32` 原子，`BCC` 超胞为 `36` 原子，采样温度为 `1`、`300` 和 `600 K`。`401` 个表面高熵合金结构则由五元 `Al-Nb-Ti-V-Zr` 体系中的 `209` 个 `(110)` 表面模型和 `192` 个 `(111)` 表面模型组成。在该表面数据集中，`Al`、`Ti`、`V` 与 `Nb` 的含量范围为 `6.2-31.2 at.%`，而 `Zr` 为 `12.5-45.8 at.%`。这些表面构型包括 `FCC`、`BCC` 与 `HCP` 薄板，并根据结构类型采用 `24` 或 `32` 原子超胞，在 `300` 与 `600 K` 下采样。

为了扩展超出初始 `QE` 标注结构的构型覆盖范围，作者依照 `DP-GEN` 的并发学习策略，在 `LAMMPS` 中进行了额外的热力学采样，随后再由 `DFT` 对采样得到的候选结构进行标注。根据表 `S4`，作者在 `0 kbar` 条件下进行了 `1` 次 `NPT` 采样迭代，温度在 `500 ps` 内从 `100 K` 升高到 `300 K`。整个数据集来自一个将变胞分子动力学（`VC-MD`）与自洽场（`SCF`）计算结合起来的流程，计算条件为 `0 kbar` 和 `1`、`300`、`600 K`。所有计算均采用 `100` 个离子步，离子时间步长为 `1 fs`，波函数动能截断为 `40 Ry`，电荷密度与势能的动能截断为 `320 Ry`，自洽收敛阈值为 `2 × 10^-5 Ry`，采用 `SSSP efficiency v1.3.0` 赝势 [21]，并使用 `Materials Cloud` 的 `Coarse` `k` 点设置。总体而言，共有 `2373` 个 `DFT` 标注帧被用于 `DLP` 训练。

#### 2.2 深度学习势训练

表 `2` 总结了开发本文 `DLP` 所采用的 `DeepMD` 训练设置。局域原子环境使用平滑版描述符 `se_a` 表征，截断半径（`rcut`）为 `8.5 Å`，平滑半径（`rsmth`）为 `2.77 Å`。嵌入网络包含 `3` 个隐藏层，其规模为 `{25, 50, 100}`；拟合网络同样包含 `3` 个隐藏层，其规模为 `{240, 240, 240}`。为了提升模型的稳健性，作者在相同超参数设置下训练了 `4` 个独立初始化的模型。

训练流程分为两个阶段：与标注流程相关的训练阶段为 `5 × 10^5` 步，最终训练阶段为 `2.5 × 10^6` 步。在优化过程中，损失函数的前因子被逐步调整，以平衡能量、力与维里量的相对贡献。具体而言，能量权重前因子 `$P_e$` 从 `0.01` 增加到 `1`，力权重前因子 `$P_f$` 从 `1000` 降低到 `5`，维里量权重前因子 `$P_v$` 从 `10` 降低到 `0.01`。这种加权策略意味着，在训练早期更强调力的匹配，而随着训练推进，则逐渐提高能量一致性的贡献。

#### 2.3 分子动力学模拟

所有经典 `MD` 模拟均使用与训练后 `DLP` 耦合的 `LAMMPS` 软件包 [22] 完成。对于 `AlNbTiVZr` 和 `Al0.5NbTiVZr0.5` 两种成分，其初始 `BCC` 结构均通过基于最大熵原理的 `Maximum Entropy Monte Carlo`（`MaxEnt MC`）算法生成 [23]。

这种方法旨在通过促进更均匀的元素分布，来近似一种高度混合、具有近最大构型熵的构型；在这种构型中，任一原子周围最近邻环境倾向于呈现化学异质性。`MaxEnt MC` 算法的具体实现包括初始化、随机交换、接受准则和收敛条件 [23]。用于弹性常数计算的模拟超胞包含 `1024` 个原子，而用于单轴拉伸模拟的大尺度超胞则包含 `13500` 个原子，并在三个方向均施加周期性边界条件。对应的原子模型见补充图 `S1`。

晶体材料在绝对零度（`0 K`）下的弹性常数张量通过有限应变法计算得到。具体做法是：在 `Voigt` 记号下的 `6` 个方向上向模拟盒施加微小的正、负应变，让原子弛豫至各自局域能量极小点，再通过数值微分测量应力变化的斜率。随后，利用 `ElasticPOST` 软件，并基于 `Voigt-Reuss-Hill` 近似，计算多晶体的弹性模量，即体模量 `B`、剪切模量 `G` 和杨氏模量 `E` [24, 25]。

单轴拉伸变形通过沿 `z` 方向对模拟盒施加形变来实现，工程应变率为 `2 × 10^8 s^-1`，对应于每 `5 ps` 增加 `0.001` 的应变增量；模拟在 `300 K`、`NPT` 系综下进行。加载过程中，`x` 和 `y` 方向的横向压力维持在 `0 kbar`。本文报告的轴向拉伸应力，对应于单轴加载过程中体系平均维里应力张量的 `zz` 分量。屈服强度和屈服应变由模拟应力 - 应变曲线通过 `0.2%` 偏移准则确定。变形过程中原子结构演化则采用 `OVITO` 中实现的多面体模板匹配（`PTM`）方法进行分析，以识别局域晶体结构（`BCC`、`FCC`、`HCP` 以及其他 / 无序）[26]。

## 结论翻译

本文针对 `Al-Nb-Ti-V-Zr` 难熔高熵合金体系开发了一种 `DLP`，并将其用于等原子比 `AlNbTiVZr` 与非等原子比 `Al0.5NbTiVZr0.5` 的大尺度分子动力学模拟。该 `DLP` 通过与 `DFT` 参考数据进行对比得到了验证，所比较的内容包括能量、力、维里量、能量 - 体积关系以及广义层错能趋势。经过验证的模型使作者能够对这两种 `BCC` 基合金中与成分相关的弹性性质、拉伸变形以及局域结构演化开展原子尺度研究。

局域弛豫分析表明，降低 `Al` 与 `Zr` 含量能够抑制静态晶格畸变。与等原子比 `AlNbTiVZr` 相比，`Al0.5NbTiVZr0.5` 具有更小的元素分辨弛豫位移和更窄的位移分布。这说明其 `BCC` 基局域环境更加均匀。畸变减弱这一点也反映在弹性性质中：`Al0.5NbTiVZr0.5` 具有更高的 `$C_{11}$`、`$C_{44}$`、剪切模量和杨氏模量，同时 `Zener` 各向异性因子更低，表明其抵抗轴向与剪切变形的能力增强，而弹性各向异性减弱。

在单轴拉伸过程中，两种合金都经历了从初始 `BCC` 类局域环境逐步向更多 `FCC`、`HCP` 和无序结构转变的应变诱导结构重排。然而，`Al0.5NbTiVZr0.5` 在变形过程中能够更有效地保持 `BCC` 框架。在极限抗拉状态下，`Al0.5NbTiVZr0.5` 的 `BCC` 类分数仍保持在 `61.2%`，而 `AlNbTiVZr` 仅为 `37.0%`。这种 `BCC` 框架退化的延后，伴随着拉伸性能的提升：屈服强度由 `5.529` 提高到 `6.621 GPa`，极限抗拉强度由 `15.353` 提高到 `17.069 GPa`，极限拉伸应变由 `0.172` 提高到 `0.191`。

原子体积分析进一步表明，拉伸变形会诱发化学上不均匀的体积非均匀性。以 `Zr` 为中心的局域环境在变形过程中表现出最大的局域原子体积和最显著的分布展宽，而以 `V` 为中心的局域环境则保持相对紧凑。`Al0.5NbTiVZr0.5` 中原子体积非均匀性的增长较弱，说明降低 `Al` 与 `Zr` 含量能够同时缓解位置型与体积型的局域畸变。总体而言，`Al0.5NbTiVZr0.5` 更优的拉伸响应来源于：畸变更弱的 `BCC` 框架、更高的剪切相关刚度、延后的 `BCC` 结构退化，以及局域体积非均匀性累积的抑制。

### 第 3 部分：结果与讨论

#### 3.1 深度学习势验证

图 `1` 给出了训练集（`95%`）与验证集（`5%`）中能量、力和维里量的 `DLP-DFT` 对比散点图。对比图显示，每原子能量的一致性最高，数据点紧密分布在对角线附近；相比之下，力与维里量的数据散布逐渐增大，但仍与 `DFT` 参考值保持清晰的整体相关性。当前 `DLP` 在每原子能量上的误差最小，并且在所采样构型范围内，对力和维里量也保持了合理精度。表 `3` 总结了相应的数值精度指标。对于每原子能量，均方根误差（`RMSE`）和平均绝对误差（`MAE`）分别为 `0.048` 和 `0.033 eV atom^-1`，训练子集和验证子集上的决定系数（`R^2`）分别为 `0.996` 和 `0.995`。对于力，`RMSE` 分别为 `0.097` 和 `0.098 eV Å^-1`，`MAE` 分别为 `0.069` 和 `0.070 eV Å^-1`，`R^2` 分别为 `0.954` 和 `0.953`。对于维里量，训练子集和验证子集上的 `RMSE` 分别为 `1.782` 和 `1.755 eV`，`MAE` 分别为 `1.014` 和 `1.015 eV`，`R^2` 分别为 `0.942` 和 `0.927`。这些对比图与误差指标表明，当前 `DLP` 能够高精度捕捉 `Al-Nb-Ti-V-Zr` 体系的能量学特征，并以可接受的保真度复现力和维里量；这对该类合金尤为重要，因为其局域环境在化学上是异质的，并且可能受到无序化、初始有序化趋势以及第二相形成倾向的影响。

图 `2` 进一步表明，该 `DLP` 能够同时捕捉 `AlNbTiVZr` 与 `Al0.5NbTiVZr0.5` 的 `DFT` 能量 - 体积关系中的平衡体积极小值以及平衡附近的曲率，这说明该模型不仅复现了离散的参考能量，还再现了与体相弹性和有限应变相关的连续体积响应。除这一体积响应验证之外，补充图 `S2` 还评估了等原子比 `AlNbTiVZr` 在 `(001)` 面上沿对应于 `[100]` 和 `[111]` 方向的两条归一化位移路径的广义层错能（`GSFE`）。这些 `GSFE` 曲线反映了与局域剪切、缺陷形核以及塑性变形早期阶段相关的滑移势垒势能曲面 [27]。比较结果表明，当前 `DLP` 能够以合理的一致性复现 `DFT` 结果的整体 `GSFE` 趋势及主要势垒特征。能量 - 体积关系与 `GSFE` 的比较共同说明，该 `DLP` 既能描述近平衡体积响应，也能描述与后续力学分析相关的剪切势垒能学特征。

#### 3.2 局域结构与晶格畸变分析

在分析弹性性质和拉伸变形之前，首先需要确认初始 `BCC` 构型是否能物理合理地表征化学无序的高熵固溶体。本文所使用的原子结构并非通过简单随机赋值生成，而是通过 `MaxEnt MC` 过程构建。在该过程中，三个方向均施加周期性边界条件，并进行 `100000` 次蒙特卡罗原子交换，以促进元素在第一近邻壳层内形成化学异质分布。这种处理减少了人为的短程团聚现象，并帮助有限尺寸超胞更好地近似化学无序的高熵固溶体，从而使后续的晶格畸变和力学分析更少受到随机有限尺寸采样的影响 [23]。

图 `3` 通过 `AlNbTiVZr` 与 `Al0.5NbTiVZr0.5` 的部分径向分布函数（`PRDFs`）考察了由 `MaxEnt MC` 生成的 `BCC` 结构中的局域原子对统计特征。同类原子对与异类原子对的分离表明，最近邻环境具有明显的化学依赖性：不同元素对表现出不同的峰位、峰宽和相对峰强，而不是共享单一的原子对间距分布。尤其是，异类原子对主导了第一近邻区，而同类原子对在第一壳层中的峰值相对较弱。这一结果说明，由 `MaxEnt MC` 生成的结构在最近邻尺度上并不存在显著的同元素团聚，而是保持了化学混合的局域环境。与等原子比 `AlNbTiVZr` 相比，`Al0.5NbTiVZr0.5` 的峰强和原子对距离分布发生了变化，这表明同时降低 `Al` 和 `Zr` 含量，改变的是局域化学原子对环境，而不仅仅是使所有近邻距离发生统一平移。

图 `4` 定量给出了相对于理想 `BCC` 晶格的逐元素弛豫位移。这些位移幅值在本文中被用作结构弛豫后静态局域晶格畸变的原子尺度度量 [28]。在 `AlNbTiVZr` 中，`Al`、`Nb`、`Ti`、`V` 和 `Zr` 的平均位移分别约为 `0.256 Å`、`0.193 Å`、`0.214 Å`、`0.192 Å` 和 `0.166 Å`。在 `Al0.5NbTiVZr0.5` 中，相应数值分别降低到约 `0.198 Å`、`0.153 Å`、`0.153 Å`、`0.139 Å` 和 `0.126 Å`。小提琴图展示了每种元素完整的位移分布，其中中间虚线表示平均位移，上下虚线分别表示高于和低于平均值 `1` 个标准差的位置。与柱状图结果一致，小提琴图表明，非等原子比合金中 `5` 种元素的位移分布都更窄。这些结果说明，`Al0.5NbTiVZr0.5` 在弛豫后更接近理想 `BCC` 参考晶格，并且其静态畸变场比等原子比 `AlNbTiVZr` 更均匀。

图 `4` 中逐元素位移趋势不能仅通过经典的原子半径失配模型加以解释。根据补充表 `S5`，原子半径大小规律为 `Zr (1.60 Å) > Ti (1.462 Å) > Al (1.432 Å) ≈ Nb (1.429 Å) > V (1.316 Å)`。如果局域弛豫只由各向同性尺寸失配控制，则原子半径最大的 `Zr` 应当表现出最大位移。然而，图 `4` 显示出相反趋势：在等原子比 `AlNbTiVZr` 中，`Al` 表现出最大的平均弛豫位移，而 `Zr` 的位移最小。这一反差说明，局域晶格弛豫并不单纯由几何堆积或球形原子尺寸效应决定，而是强烈受到化学无序 `BCC` 基体中局域化学环境、成键异质性以及近邻原子施加的方向依赖力平衡影响 [11, 28-31]。

这一行为可以通过考察 `Al` 如何改变 `BCC` 过渡金属基体中的局域电子结构和成键环境来理解。在富 `NbVTiZr` 的 `BCC` 晶格中，邻近过渡金属原子包含部分占据的 `d` 态，这些 `d` 态能够向附近原子提供电子密度。相比之下，`Al` 是第 `13` 族元素，具有来源于 `p` 轨道的受电子态，因此可以表现为局域电子受体中心 [32]。当 `Al` 被 `Nb`、`V`、`Ti` 和 `Zr` 原子包围时，部分来自过渡金属 `d` 态的电子密度会重新分配到以 `Al` 为中心的局域环境中。从概念上看，这类似于一种路易斯酸碱相互作用，其中过渡金属充当电子给体，而 `Al` 充当电子受体；尽管这里的相互作用发生在延展金属合金中，而不是孤立分子体系内 [32]。这种电荷重分配使局域成键从纯金属性且近似各向同性的相互作用，转变为对方向更敏感的 `Al-过渡金属` 相互作用。更具体地说，`Al-p` 态能够与邻近过渡金属原子的 `d` 态发生杂化，形成 `Al-p / transition-metal-d` 成键组分。由于 `p` 和 `d` 轨道具有方向性，它们的重叠依赖于周围原子的相对位置与取向。因此，作用在 `Al` 原子上的力并不是由原子尺寸失配导致的简单均匀径向力，而是一个取决于最近邻化学身份及空间排布的各向异性局域力场 [33]。

这种方向敏感的 `Al-过渡金属` 成键，为图 `4` 中观察到的异常大的 `Al` 弛豫位移提供了更清晰的解释，尽管 `Al` 的原子半径与 `Nb` 接近。如果弛豫仅由原子尺寸失配控制，那么理想 `BCC` 晶格中的置换原子主要会引起其周围配位壳层近似对称的膨胀或收缩；在这种情况下，来自邻近原子的作用力大体相互抵消，原子会保持接近其理想晶体学位置。然而，在化学无序的 `AlNbTiVZr` 合金中，`Al` 并非如此。围绕每个 `Al` 原子的近邻位点由不同组合的 `Nb`、`V`、`Ti` 和 `Zr` 占据。由于这些元素具有不同的 `d` 态特征以及与 `Al` 不同的成键倾向，`Al-p / transition-metal-d` 相互作用在各个方向上的强度并不相同。于是，一些 `Al-过渡金属` 键会在局部变得更强或更具方向性。结果是，作用在 `Al` 原子上的力不能对称抵消，`Al` 倾向于偏离理想 `BCC` 位置，移动到一个更能容纳其与周围过渡金属原子之间较强方向性成键相互作用的局域构型 [33, 34]。因此，图 `4(a)` 和图 `4(c)` 中较大的 `Al` 位移应理解为由局域化学和电子结构不对称性驱动的偏心弛豫，而不是由原子尺寸失配造成的简单径向位移。随机的化学排布已经使每个以 `Al` 为中心的环境在局部上彼此不同，而 `Al-p / transition-metal-d` 杂化的角向特征进一步增强了这种不对称性。

这一解释也说明了，为什么 `Zr` 虽然在构成元素中原子半径最大，却在图 `4` 中表现出相对较小的弛豫位移。`Zr` 位移较小并不意味着它对晶格畸变影响很弱；相反，这说明 `Zr` 扭曲晶格的方式与 `Al` 不同。由于 `Zr` 明显大于其他元素，以 `Zr` 为中心的局域环境往往会扩张周围配位壳层，并提高局域原子体积。在这种情况下，由尺寸引起的部分应变可以通过邻近原子的向外调整以及局域体积膨胀来吸收。因此，即使其周围环境已经发生畸变，`Zr` 原子自身仍能够保持相对接近理想 `BCC` 位置。

这种行为与前文讨论的以 `Al` 为中心的弛豫不同。`Al` 产生最大位移并不是因为原子尺寸，而是因为 `Al-p / transition-metal-d` 相互作用具有方向依赖性，且在所有近邻方向上强度并不相同。换句话说，`Zr` 主要通过与尺寸相关的局域膨胀来贡献晶格畸变，而 `Al` 主要通过对化学环境敏感、具有方向性且偏心的弛豫来贡献晶格畸变。这两种效应都会扰动 `BCC` 晶格，但表现形式不同：`Zr` 更密切关联于局域体积非均匀性，而 `Al` 更密切关联于不对称的位置弛豫。

因此，`Al0.5NbTiVZr0.5` 中较小的位移幅值可以理解为两类局域畸变源同时减少的结果。降低 `Al` 含量会减少那些能够通过方向性 `Al-p / transition-metal-d` 成键产生不对称局域力的 `Al` 中心环境数量；同时，降低 `Zr` 含量则会减少那些能够扩张局域配位壳层并增加堆积相关应变的大原子环境数量。结果是，非等原子比合金中强烈扰动局域力平衡的位置更少，其局域环境更多由 `Nb`、`Ti` 和 `V` 富集环境主导，而这些元素的原子尺寸和过渡金属 `d` 电子特征彼此更接近。这样更均匀的局域环境使 `Al0.5NbTiVZr0.5` 在弛豫后能够更接近理想 `BCC` 框架，这一点体现在图 `4` 中更小的平均位移和更窄的位移分布上。

当前 `DLP` 并不显式输出电荷密度、轨道占据数或 `Bader` 电荷。然而，由于它是在来源于 `DFT` 的能量和原子力数据上训练得到的，其拟合的势能曲面已经隐含包含了底层电子结构所产生的力学特征 [35]。因此，与具有固定解析函数形式的传统经验势相比，该 `DLP` 能更灵活地捕捉与局域成键异质性相关、依赖环境的多体弛豫响应。

#### 3.3 结构与弹性性质

表 `4` 总结了 `AlNbTiVZr` 与 `Al0.5NbTiVZr0.5` 的晶格参数、单晶弹性常数以及导出的多晶弹性模量。在当前立方态弹性近似下，两种成分均满足立方晶体的 `Born` 力学稳定性判据，即 `$C_{11} > 0$`、`$C_{44} > 0$`、`$C_{11} > C_{12}$` 以及 `$C_{11} + 2C_{12} > 0$`。这表明，在假设的 `BCC` 基立方结构描述下，计算得到的弹性张量在力学上是允许的，并为后续解释其方向性弹性各向异性提供了必要基础。

对于等原子比 `AlNbTiVZr`，计算得到的晶格常数为 `0.328 nm`，并具有 `$C_{11} = 132.83 GPa$`、`$C_{12} = 108.03 GPa$`、`$C_{44} = 51.02 GPa$`、`$B = 116.30 GPa$`、`$G = 29.14 GPa$` 和 `$E = 80.70 GPa$`。相比之下，`Al0.5NbTiVZr0.5` 的晶格常数略小，为 `0.325 nm`，并表现出 `$C_{11} = 151.21 GPa$`、`$C_{12} = 103.72 GPa$`、`$C_{44} = 54.57 GPa$`、`$B = 119.55 GPa$`、`$G = 39.08 GPa$` 和 `$E = 105.72 GPa$`。因此，非等原子比合金表现出更高的轴向与剪切相关刚度，这体现在 `$C_{11}$`、`$C_{44}$`、`$G$` 和 `$E$` 的提升上，而体模量变化较小。这表明，成分效应对定向变形和剪切变形抗力的影响，比对各向同性压缩抗力的影响更为显著。

这种刚度差异与前一节的晶格畸变分析是一致的。`AlNbTiVZr` 中更大的弛豫位移和更宽的位移分布表明，其局域应变场更加异质，这可能削弱 `BCC` 晶格抵抗微小轴向和剪切扰动的能力。相比之下，`Al0.5NbTiVZr0.5` 中更弱的静态畸变，与其更高的 `$C_{11}$`、`$G$` 和 `$E$` 数值相一致。

图 `5` 展示了两种合金弹性模量的方向依赖性。在当前立方态弹性近似下，体模量表面几乎保持球形，反映出其静水响应几乎与方向无关。相比之下，杨氏模量 `$E$` 和剪切模量 `$G$` 的表面明显偏离球形，表明两种成分都具有弹性各向异性。等原子比 `AlNbTiVZr` 的 `$E$` 和 `$G$` 表面起伏更强，而 `Al0.5NbTiVZr0.5` 的对应表面则畸变较小。这一趋势说明，降低 `Al` 与 `Zr` 含量会减弱但不会完全消除弹性响应的方向依赖性。定量上，与立方 `BCC` 合金四方剪切抗力和 `Born` 稳定性条件相关的弹性差值项 `$C_{11} - C_{12}$`，由 `AlNbTiVZr` 中的 `24.80 GPa` 增加到 `Al0.5NbTiVZr0.5` 中的 `47.49 GPa` [24]。与此同时，`Zener` 各向异性因子 `$A = 2C_{44} / (C_{11} - C_{12})$` 由 `4.11` 降至 `2.30`。`Zener` 因子是衡量立方晶体弹性各向异性的常规指标，其中 `$A = 1$` 对应弹性各向同性极限 [36]。因此，尽管 `$A$` 的降低使 `Al0.5NbTiVZr0.5` 更接近立方弹性各向同性，但其数值仍大于 `1`，这表明该非等原子比合金仍然具有弹性各向异性。

这种由成分引起的弹性各向异性降低，可以直接与 `3.2` 节讨论的局域弛豫行为联系起来。如图 `4` 所示，`Al0.5NbTiVZr0.5` 的逐元素弛豫位移更小、位移分布更窄，这意味着在弛豫后，其原子更接近理想 `BCC` 晶格位置，位点与位点之间的结构差异程度也更低。相比之下，`AlNbTiVZr` 中更大且更宽的位移分布表明其局域环境更异质，不同原子位点经历不同的局域力平衡和不同的键刚度。

这种局域畸变差异为图 `5` 中的弹性模量曲面提供了物理解释。在化学无序的 `BCC` 合金中，对轴向与剪切变形的抗力不仅由平均晶格常数决定，还取决于局域键对不同晶体学方向变形的抗力是否足够均匀。当局域晶格畸变很强时，例如在等原子比 `AlNbTiVZr` 中，一些原子环境会因 `Al` 中心方向性成键、`Al-Zr` 化学亲和以及 `Zr` 相关尺寸失配的共同作用而相对更硬，而另一些环境则相对更软。这种空间上不均匀的键刚度会使弹性响应更强地依赖方向，从而导致图 `5` 中观察到的更明显畸变的杨氏模量和剪切模量曲面。这一解释与第一性原理研究结果一致，即局域化学有序、`Al-Zr` 成键、依赖溶质的电子描述符以及 `Al-p / transition-metal-d` 相互作用，都能够影响含 `Al` 的 `RHEAs` 的结构稳定性、成键特征和力学行为 [11, 29-34]。

因此，`Al0.5NbTiVZr0.5` 较小的弹性各向异性可以理解为两类主要局域异质性来源被削弱后的结果。首先，降低 `Al` 含量会减少那些因电荷重分配和方向性 `Al-p / transition-metal-d` 杂化而产生不对称局域力的 `Al` 中心环境；其次，降低 `Zr` 含量会减少那些引入强烈堆积相关应变和局域体积膨胀的大原子环境。随着化学上和几何上都较极端的局域环境变少，`Al0.5NbTiVZr0.5` 形成了更均匀的 `BCC` 基结构。这种更均匀的局域结构使其在不同方向上的变形抗力更加平衡，从而解释了它相对于等原子比 `AlNbTiVZr` 所表现出的更高剪切相关刚度和更低 `Zener` 各向异性因子。因此，图 `5` 中的弹性模量曲面应被视为图 `4` 所量化的逐元素局域弛豫行为在宏观上的表现。

#### 3.4 拉伸变形与力学响应

屈服强度 `$σ_{YS}$` 与屈服应变 `$ε_{YS}$` 通过 `0.2%` 偏移准则确定，而极限抗拉强度 `$σ_{UTS}$` 与对应应变 `$ε_{UTS}$` 则分别对应应力最大值及其所在应变。基于这些定义，图 `6` 和图 `7` 对比了等原子比 `AlNbTiVZr` 与非等原子比 `Al0.5NbTiVZr0.5` 的拉伸响应，以及被分类为 `BCC`、`FCC`、`HCP` 和 `Other` 的局域结构随应变的演化。在两种合金中，未变形构型均以 `BCC` 类局域环境为主。在早期加载阶段，拉伸应力近似线性增加，并且直到屈服点前，`BCC` 分数始终不低于 `94.6%`。这说明，从弹性阶段到屈服阶段的变形主要是在 `BCC` 主导的局域结构框架内完成的。屈服之后，应力 - 应变响应进入塑性变形阶段，此时 `BCC` 分数更明显地下降，而 `FCC`、`HCP` 与 `Other` 类局域环境的分数逐渐增加。这一趋势表明，塑性变形伴随着应变诱导的局域结构重排，而不是初始 `BCC` 晶格的纯仿射拉伸。

图 `6(b)` 和图 `7(b)` 中的代表性原子构型进一步阐明了所选应变状态的物理含义。快照 `(I)` 对应拉伸前初始弛豫的 `BCC` 主导结构。快照 `(II)` 表示屈服点，此时 `BCC` 基体仍然大部分保留，只有少量非 `BCC` 局域环境出现。快照 `(III)` 对应中间塑性变形阶段，此时 `FCC`、`HCP` 和无序局域环境开始明显积累，反映出 `BCC` 基体内部逐步增强的局域结构失稳。快照 `(IV)` 标记极限抗拉状态，此时 `AlNbTiVZr` 在 `$ε_{UTS} = 0.172$` 处达到 `$σ_{UTS}$`，而 `Al0.5NbTiVZr0.5` 在 `$ε_{UTS} = 0.191$` 处达到 `$σ_{UTS}$`。快照 `(V)` 则表示峰值应力之后的断裂阶段，其特征是严重的变形局域化、承载连续性的丧失以及变形结构呈现出类似断裂分离的形貌。

为了定量比较与成分相关的 `BCC` 框架保留能力，表 `5` 总结了图 `6` 和图 `7` 中所标识的 `5` 个代表性应变状态下 `BCC` 类局域环境的分数。在未变形态，`AlNbTiVZr` 和 `Al0.5NbTiVZr0.5` 的 `BCC` 分数分别为 `97.9%` 和 `99.9%`。在屈服点，两种合金的 `BCC` 分数仍然很高，分别为 `94.6%` 和 `99.0%`。屈服后，两种合金之间的差异开始更加明显。在由快照 `(III)` 表征的中间塑性变形状态下，`AlNbTiVZr` 的 `BCC` 分数降至 `80.4%`，而 `Al0.5NbTiVZr0.5` 仍保持 `88.7%` 的 `BCC` 类局域环境。在极限抗拉状态下，`AlNbTiVZr` 在 `$ε_{UTS} = 0.172$` 处达到 `$σ_{UTS} = 15.353 GPa$`，此时 `BCC` 分数急剧降至 `37.0%`。相比之下，`Al0.5NbTiVZr0.5` 在更大的 `$ε_{UTS} = 0.191$` 处达到更高的 `$σ_{UTS} = 17.069 GPa$`，同时仍保留 `61.2%` 的 `BCC` 类局域环境。这些结果表明，在峰后应力骤降之前的更宽应变区间内，非等原子比合金能够保持更大比例的 `BCC` 类局域环境。

两种合金中看似出现的 `BCC` 类局域环境“回升”发生在不同的力学阶段。对于 `AlNbTiVZr`，`BCC` 分数从极限抗拉状态下的 `37.0%` 增加到断裂阶段的 `54.4%`。然而，这种增加出现在应力峰值之后，不应被解释为一个真正恢复的、力学稳定的 `BCC` 框架。更合理的解释是卸载或断裂诱导的局域重新分类，也就是说，当承载网络塌陷后，破碎基体中的一部分局部构型在弛豫过程中重新趋近于 `BCC` 类几何。相比之下，`Al0.5NbTiVZr0.5` 在极限抗拉状态下仍保留 `61.2%` 的 `BCC` 类局域环境，并在断裂阶段表现为 `54.3%`。更重要的是，它在达到极限抗拉状态之前的短暂 `BCC` 保留发生于拉伸应力仍在增加的过程中，这表明非等原子比合金在持续加载下能更有效地保持 `BCC` 类局域有序。

相应的拉伸力学性能总结于表 `6`。对于 `AlNbTiVZr`，`$σ_{YS}$`、`$ε_{YS}$`、`$σ_{UTS}$` 和 `$ε_{UTS}$` 分别为 `5.529 GPa`、`0.046`、`15.353 GPa` 和 `0.172`。对于 `Al0.5NbTiVZr0.5`，对应数值分别增加到 `6.621 GPa`、`0.049`、`17.069 GPa` 和 `0.191`。因此，在当前拉伸模拟方案下，非等原子比合金表现出更高的屈服强度、更高的极限抗拉强度以及更大的峰值应力对应应变。

`Al0.5NbTiVZr0.5` 中结构退化的延后，与前文的晶格畸变和弹性性质分析一致。与等原子比 `AlNbTiVZr` 相比，非等原子比合金具有更小的静态弛豫位移以及更高的 `$C_{11}$`、`$C_{44}$`、`$G$` 和 `$E$`，这说明其 `BCC` 框架畸变更弱且力学上更刚硬。降低 `Al` 含量会减少那些与方向性 `Al-p / transition-metal-d` 成键和偏心弛豫相关的 `Al` 中心环境，而降低 `Zr` 含量则会减少那些促进局域体积膨胀和体积非均匀性的“大原子”环境。这样更均匀的 `BCC` 基体，使 `Al0.5NbTiVZr0.5` 能在保留更多 `BCC` 类局域有序的同时承受更高的拉伸载荷，直至达到极限抗拉状态。因此，`Al0.5NbTiVZr0.5` 拉伸响应的改善，不仅体现在更高的 `$σ_{YS}$` 和 `$σ_{UTS}$` 数值上，也体现在其从 `BCC` 主导局域结构向高度异质变形态转变的过程被推迟。

#### 3.5 变形的原子尺度分析

为了进一步将拉伸响应与局域体积变形联系起来，作者比较了未变形态与极限抗拉强度状态下的原子体积分布。未变形态 `$ε = 0$` 代表加载前初始弛豫的 `BCC` 构型，而 `$ε_{UTS}$` 状态则对应于拉伸应力在峰后结构退化之前达到最大值的关键力学状态。通过这一比较，可以在最具代表性的高载荷状态下评估变形诱导的平均原子体积变化以及微观体积非均匀性的演化。图 `8` 中，`$μ$` 表示平均原子体积，`$σ$` 表示相应原子体积分布的标准差。每个小提琴图内部的水平虚线表示四分位区间和中位数，为分布宽度和中心位置提供了直观度量。分布从 `$ε = 0$` 到 `$ε_{UTS}$` 的整体上移表明拉伸膨胀，而小提琴图的展宽及更大的 `$σ$` 值则表明拉伸过程中局域体积非均匀性的增长。

图 `8` 给出了两种合金在 `$ε = 0$` 与 `$ε_{UTS}$` 下的整体及逐元素原子体积分布分裂小提琴图。图 `8(a)` 对应 `AlNbTiVZr`，其 `$ε_{UTS}$` 发生在 `$ε = 0.172$`；图 `8(b)` 对应 `Al0.5NbTiVZr0.5`，其 `$ε_{UTS}$` 发生在 `$ε = 0.191$`。在两种合金中，整体原子体积分布在拉伸载荷下都向更大体积方向移动。对于 `AlNbTiVZr`，平均原子体积 `$μ$` 从约 `17.8` 增加到 `20.9 Å^3`，而标准差 `$σ$` 从约 `1.0` 增加到 `1.9 Å^3`。对于 `Al0.5NbTiVZr0.5`，`$μ$` 从约 `17.2` 增加到 `20.5 Å^3`，而 `$σ$` 从约 `0.8` 增加到 `1.6 Å^3`。这些结果表明，两种合金在 `$ε_{UTS}$` 状态下都经历了整体拉伸膨胀以及分布展宽。

小提琴图的宽度为局域原子体积的离散程度提供了直接的视觉度量。`$ε_{UTS}$` 下更宽的分布表明，拉伸载荷增加了局域体积环境的多样性，也就是说，一些原子经历了比其他原子更强的局域膨胀。这种变形诱导的展宽在 `AlNbTiVZr` 中比在 `Al0.5NbTiVZr0.5` 中更明显，这一点体现在前者在 `$ε_{UTS}$` 下具有更大的整体 `$σ$`。因此，尽管两种合金在拉伸下都会膨胀，但等原子比合金在高载荷状态下发展出更强的微观体积非均匀性。相比之下，`Al0.5NbTiVZr0.5` 从更窄的初始未变形分布出发，并在 `$ε_{UTS}$` 下保持更小的整体 `$σ$`，这表明其局域体积分布在拉伸变形过程中保持得更均匀。

这种分布宽度上的差异，与图 `6`、图 `7` 和表 `5` 中讨论的局域结构演化是一致的。在达到极限抗拉状态之前，`Al0.5NbTiVZr0.5` 比 `AlNbTiVZr` 保留了更大比例的 `BCC` 类局域环境。在中间塑性变形状态下，`Al0.5NbTiVZr0.5` 的 `BCC` 分数为 `88.7%`，而 `AlNbTiVZr` 仅为 `80.4%`。在 `$ε_{UTS}$` 处，`Al0.5NbTiVZr0.5` 仍保留 `61.2%` 的 `BCC` 类局域环境，而 `AlNbTiVZr` 则急剧下降到 `37.0%`。因此，`Al0.5NbTiVZr0.5` 更窄的原子体积分布反映了其 `BCC` 结构退化被推迟，以及在极限抗拉状态前局域体积非均匀性积累较弱。

逐元素小提琴图进一步表明，变形诱导的体积变化发生在所有构成元素中，而不是局限于某一种元素。在图 `8(a)` 和图 `8(b)` 中，`Al`、`Nb`、`Ti`、`V` 和 `Zr` 对应的分布都从 `$ε = 0$` 向 `$ε_{UTS}$` 移动到更大的原子体积，这说明所有化学组元都经历了拉伸膨胀。同时，拉伸后这些分布都变得更宽，表明同一种元素的原子不再占据狭窄而均匀的局域体积环境。相反，更宽的分布意味着，同一种元素的原子会根据其局域化学环境，在拉伸过程中经历不同程度的局域膨胀。

在所有构成元素中，以 `Zr` 为中心的局域环境在变形后表现出最大的原子体积，而以 `V` 为中心的局域环境则对应最小的原子体积。这一趋势与 `Zr` 较大的原子尺寸和 `V` 较小的原子尺寸一致。`Zr` 分布的展宽表明，以 `Zr` 为中心的局域环境在拉伸载荷下对原子体积分布的高体积尾部贡献显著。相比之下，以 `V` 为中心的环境则集中在较小体积区域。因此，拉伸变形并不会产生一种在化学上均匀的体积膨胀；相反，它会放大逐元素依赖的体积非均匀性，其中富 `Zr` 局域环境承担更大的局域膨胀，而 `V` 中心环境则保持相对紧凑。

图 `9` 总结了等原子比 `AlNbTiVZr` 与非等原子比 `Al0.5NbTiVZr0.5` 在单轴拉伸过程中的原子体积统计随应变的演化。图中将两种合金绘制在同一坐标系中，以直接比较在各自加载路径上，直至极限拉伸应变之前局域体积非均匀性如何发展，其中 `AlNbTiVZr` 的 `$ε_{UTS} = 0.172$`，`Al0.5NbTiVZr0.5` 的 `$ε_{UTS} = 0.191$`。图 `9(a)` 给出整体平均原子体积 `$μ$`，图 `9(b)` 给出整体标准差 `$σ$`，图 `9(c)` 给出逐元素平均原子体积。在图 `9(c)` 中，阴影带表示逐元素平均值上下各 `1` 个标准差，因此可视化地反映了每种元素局域原子体积变化的下界与上界。

图 `9(a)` 和图 `9(b)` 的整体趋势表明，两种合金在加载过程中都经历了持续的拉伸膨胀。整体 `$μ$` 随应变持续增加，说明局域原子体积在拉伸下整体扩张。同时，整体 `$σ$` 也不断增加，这说明拉伸变形不仅带来平均体积膨胀，还伴随着微观体积非均匀性的逐渐累积。然而，这种累积明显依赖于成分。`AlNbTiVZr` 从更大的初始 `$σ$` 出发，并在应变接近 `$ε_{UTS}$` 时增长更快；而 `Al0.5NbTiVZr0.5` 则从更小的 `$σ$` 起始，并在整个加载路径中表现出更缓慢的增长。这表明，非等原子比合金并没有完全消除局域体积非均匀性，而是在拉伸变形过程中抑制并延缓了其发展。

图 `9(c)` 中逐元素趋势进一步阐明了这种非均匀性如何在不同化学组元之间发展。在早期加载阶段，以 `Al`、`Nb`、`Ti`、`V` 和 `Zr` 为中心的局域环境平均原子体积都逐渐增加，而阴影带仍相对较窄。这说明初始变形主要表现为在 `BCC` 主导局域结构内相对均匀的拉伸膨胀。屈服之后以及在中间塑性变形阶段，阴影带开始展宽，这表明同一种元素的原子会因其周围化学和结构环境不同，而经历不同程度的局域膨胀。接近极限抗拉状态时，这种逐元素依赖的展宽变得更加明显，说明当 `BCC` 主导结构接近稳定性极限时，局域体积变形会变得越来越异质。

在所有构成元素中，以 `Zr` 为中心的局域环境始终表现出最大的 `$μ$`，而以 `V` 为中心的局域环境则始终对应最小的 `$μ$`。`Zr` 阴影带的上边界随应变增加得最明显，尤其是在高应变区间。这表明，一部分 `Zr` 中心局域环境在拉伸过程中经历了特别大的局域膨胀。这种行为与 `Zr` 较大的原子尺寸相一致，后者促进局域配位壳层膨胀，并使 `Zr` 中心环境对变形诱导的体积非均匀性更加敏感。因此，`Zr` 中心环境对原子体积分布的大体积一侧贡献显著，并在变形过程中局域体积不均匀性的建立中发挥主要作用。

相比之下，`V` 中心环境在整个拉伸过程中始终位于低体积分支。尽管 `V` 的 `$μ$` 也会随应变增加，但在大应变条件下，`V` 阴影带上边界并不像 `Zr` 那样持续显著上升，而是在高应变区间趋于平缓，甚至略有下降。这种行为不应被理解为 `V` 中心环境整体收缩；更合理的解释是，`V` 中心局域环境保持相对紧凑，并较少参与高度膨胀局域区域的形成。换言之，最强的局域拉伸膨胀并不是均匀分配给所有元素的，而是优先由大体积的 `Zr` 中心环境来承受，而 `V` 中心环境则更有可能维持在较为紧凑的局域构型中。

对两种合金的比较进一步表明，降低 `Al` 和 `Zr` 含量会抑制极端局域大体积环境的发展。在 `Al0.5NbTiVZr0.5` 中，无论是整体 `$σ$` 还是逐元素阴影带，在较大应变下都系统性地小于 `AlNbTiVZr`。这种减小在 `Zr` 中心环境中尤为明显，其上边界膨胀和整体展宽在非等原子比合金中都较弱。这一趋势与前述晶格畸变分析一致：等原子比 `AlNbTiVZr` 具有更大的静态弛豫位移和更异质的弛豫 `BCC` 晶格，而 `Al0.5NbTiVZr0.5` 则具有更小的位移幅值和更窄的初始畸变场。降低 `Al` 含量会减少那些与方向性 `Al-p / transition-metal-d` 成键和偏心弛豫相关的 `Al` 中心环境，而降低 `Zr` 含量则会减少那些促进局域体积膨胀的大原子环境。因此，`Al0.5NbTiVZr0.5` 能够抑制局域体积非均匀性的累积，延缓 `BCC` 主导局域结构的失稳，并最终获得比等原子比合金更大的极限拉伸应变。
