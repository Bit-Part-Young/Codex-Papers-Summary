## 论文内容详细总结

- **研究目的与定位**：论文以高熵合金（HEA）为案例，构建一个由大语言模型（LLM）从文献自动抽取的、可追溯的数据库，并报告生成该数据库的提取流程。作者将数据集视为主要科学产出，将 LLM 驱动方法定位为扩大数据构建规模所必需的手段，而非开展下游预测模型或任务性能基准。

- **语料范围与数据获取**：从可通过出版社 API 获取的受限语料中收集了 4,625 篇论文，约占 Web of Science 所列 2004 年以来 22,745 篇英文 HEA 文献的 20%。其中 Elsevier 文献 4,248 篇、Springer Nature 文献 72 篇、皇家化学学会文献 305 篇。XML 文献直接进入流程；主要以 PDF 提供的文献先由 llama-parse 转为 Markdown。抽取对象仅限事实性数值数据和短描述符，不再分发图、表或叙述性正文。

- **模型与抽取流程**：作者逐篇将论文置入 Jamba 1.5 Large 的上下文窗口，以连续的结构化提问提取信息。该模型采用 Transformer–Mamba 混合架构与 Mixture-of-Experts（MoE），总参数量 398 B、每次激活 94 B。5 个提示依次识别合金、确定晶体学相、判定研究类型、检查部分有序结构，并生成最终嵌套 JSON；后处理脚本再将 JSON 类字符串转为关系型表。

- **数据库内容与可追溯性**：生成两张表：文献级表保留各次提示的回答，合金级表记录合金式、来源论文标题、相数、实验或理论属性、实验与理论细节、特殊条件、晶体结构、DOI 与期刊。最终目标数据库从 4,625 篇同行评议论文中提取 12,427 个 HEA 条目；每一行均附来源 DOI，从而可回溯到原始论文。

- **数据库概览**：在单相合金中，FCC 占 58.8%（3,851 个），BCC 占 29.2%（1,913 个），HCP 占 1.7%（114 个），其他结构占 10.2%（669 个）。12,427 个合金的制备路线中，熔炼占 69%（8,580 个），其中电弧熔炼占全部熔炼过程的 60%（5,175 个）；机械加工占 24.8%（3,086 个），其中球磨占该类 77%（2,372 个）。元素使用频率以 Cr（68.9%）、Ni（69.8%）、Fe（65.5%）、Co（62.5%）和 Al（36.6%）为突出，反映文献主要围绕 Cantor 合金及其次级的难熔金属体系展开。

- **技术验证**：材料科学与冶金专家为随机抽取的 50 篇 HEA 文献建立人工参考答案，并分别比较 LLM 抽取结果和脚本解析后结果。评估覆盖化学式组分及准确性、相数量与种类、研究类型、合成参数及固溶体类别；可二元判定的项目用 0/1 计分，较细致项目用 0、0.5、1 计分。

- **误差来源与性能结论**：作者区分“抽取分数”和“解析分数”：前者衡量模型从原文识别材料信息的能力，后者衡量输出是否符合 JSON 模式并可表格化。脚本通常比模型低约 5–10%，因为解析增加了错误机会；化学式、研究类型和实验细节相对适合表格化。相识别的解析性能降幅最大，从 89.8% 降至 78.3%，归因于源 JSON 中浓度格式不均一、需要解释性处理；“溶液类型”则因脚本利用额外上下文修正误分类而由 82.1% 升至 84.4%。摘要报告的准确率范围为：HEA 相识别 78.7%，HEA 成分 94.3%。

## 章节翻译

### 摘要

高熵合金（HEA）是材料科学中一个很有前景的领域，但对大量文献进行系统分析仍然是一项挑战。本研究采用自然语言处理（NLP）技术分析了来自出版社可访问文献这一受限语料库的 4,625 篇科学论文，成功识别并表征了 12,427 种不同的高熵合金。通过提示工程以及对包括 Mamba–Transformer 混合架构在内的大语言模型（LLM）的实验，我们开发了一个结构化数据库，记录合金成分、相数量和晶体学结构等重要参数。在分析中，我们区分理论研究与实验研究，并分别考虑每一类的具体方法学细节。对于理论工作，我们系统记录了建模方法和关键计算参数；对于实验研究，则按其合成方法和关键工艺条件进行编目。该数据库代表了对 HEA 研究数据的大规模自动化抽取。数据准确率从 HEA 相识别的 78.7% 到 HEA 成分的 94.3% 不等。

### 引言

**位置说明**：原文将引言功能内容置于无标题的 “Background & Summary” 部分；以下为该部分全文翻译。

绿色和数字化转型将对材料产生前所未有的需求 [1,2]。人们已对能否利用现有资源满足这些材料需求产生严重担忧，因为包括铂族金属、稀土元素、镓和锗在内的若干关键元素已经面临显著的供应风险 [3]。一种很有前景的策略是开发新型替代材料，尤其是先进合金。潜在的解空间极其庞大；可能的合金组合数量大得惊人 [4]，使传统的试错式发现方法效率极低。

人工智能（AI）是加速这一材料发现过程的一条有前景的路径。然而，AI 驱动发现的有效性关键取决于能否获得广泛且可靠的材料数据库。历史上，材料数据库通过人工整理实验结果 [5] 或计算建模方法 [6] 建立。人工整理的数据库含有从同行评议科学文献中抽取的高度可靠信息，代表实验验证的结果。但是，这类数据库覆盖范围有限，且开发和维护耗时。相反，诸如 Materials Project（https://www.materialsproject.org/）等计算数据库覆盖面广得多，但其现实适用性受到质疑，因为理论预测常与实验结果不一致。ChemDataExtractor [7] 等工具带来了一项重要进展，它们可分析数万至数十万篇科学论文，自动抽取屈服强度 [8]、居里和 Néel 温度 [9]、折射率 [10]、带隙 [11]、热电优值 [12] 等有价值的物理性质。为进一步增强基于 AI 的材料发现方法的能力，还需要更多描述符与更全面的性质抽取。

本文以高熵合金（HEA）为案例，聚焦于其在与绿色和数字化转型相关的多种应用中的潜力，包括优异的力学性质 [13,14] 和催化性能 [15–17]，以及其特有的广阔成分空间。我们利用大语言模型抽取 AI 驱动 HEA 探索所需的关键数据，如相识别、晶体学和化学成分。为加速未来实验开发，我们还抽取科学文献中所述的合成方法和理论建模方法，从而为加速材料发现建立更全面的基础。两个组成部分，即（1）HEA 数据集和（2）LLM 驱动的抽取方法，构成本研究的主要科学贡献；其中，数据集是主要科学产出，而方法学则是生成它所必需的。

### 方法

**数据获取。** 根据 Web of Science（WoS），自 2004 年以来已发表 22,745 篇关于高熵合金的英文文献；其中约 80% 不能通过本研究所用 API 访问。我们从公开可访问的受限语料库中收集了 4,625 篇科学论文，约占全部 HEA 出版物的 20%。这些论文在科学出版社间的分布如表 1 所示。

该受限语料库通过各出版社 API（应用程序编程接口）的全文文章检索获得，例如 Elsevier 的 TextMining API（https://dev.elsevier.com）；它代表了更广泛 HEA 文献中出版社可访问的一个子集。相当一部分研究论文以 XML（可扩展标记语言）格式获得，这种格式提供适合 LLM 处理流程的结构化语义标记。对于来自其他出版社的文献〔皇家化学学会（https://developer.rsc.org）和 Springer（https://www.springernature.com）〕，它们主要以 PDF（便携式文档格式）提供，我们实施了一个经训练的机器学习模型，将复杂科学 PDF 版式转换为 Markdown 语法。只抽取事实性数值数据和短描述符；不再分发受版权保护的图、表或叙述性文本。文献检索需要研究机构具备的特殊认证，并需要用于精确定位的唯一标识符；检索以应用于标题、摘要和全文的关键词查询 “high entropy alloy” 或 “HEA” 实施。这些标识符为：

- 数字对象标识符（DOI）；或
- 平台特定的唯一标识符。

对于来自皇家化学学会（RSC）的出版物，时间参数（发表年份）是另一项强制检索条件。

为了将部分仅以 PDF 格式提供的论文转换为 Markdown，我们还必须采用另一个专门为此训练的语言模型：来自 llama-index 的 llama-parse 能够将含有图、表、公式等的结构化 PDF 转换为 Markdown。

**数据集生成。** 为从公开科学文献构建一个全面的高熵合金数据库，我们开发了一套系统化抽取流程。该方法依次通过大语言模型处理不同文本格式的单篇科学论文。每篇论文被载入模型的上下文窗口，随后进行一系列结构化查询。重要的是，模型在提问序列中保留先前回答，从而能在整个文献语料库中保持一致的信息抽取，并有助于构建连贯、结构化的数据集。

基于 Transformer 的架构目前主导大语言模型（LLM）领域，突出的例子包括大多数开源模型（如 Llama）及 GPT 系列等许多专有模型。结合 Transformer、Mamba 序列建模和专家混合（MoE）方法的混合架构，近年来已用于处理广大的上下文窗口。这些模型在处理完整书籍或综合性科学期刊等大量输入时，仍保持有竞争力的推理时间。在我们的分析中，使用 Jamba 1.5 Large；其总参数量为 398 B，其中激活参数为 94 B。激活参数量与总参数量的显著差异是基于 MoE 的架构 [18] 所固有的：每个输入词元仅激活一部分专家，从而在保持模型容量的同时实现高效计算。

Waleffe 等人 [19] 已广泛讨论以线性时间方式使用 Mamba 进行序列建模的概念；该方式可高效管理大体量数据而不牺牲响应时间。此外，Lieber 等人 [20] 进一步阐述了这些混合模型的具体实现细节和经验结果，证明基于 Mamba 的架构在大规模语言建模中的效用。Jamba 团队和 Lenz 等人的研究 [20,21] 还提供了关于这些近期模型设计的结构细节和运行效率的更多见解。本数据生成流程选择该方法，是因为它适合在单一上下文窗口中处理整篇科学论文，从而能在整个文献内实现一致的信息抽取。

**提示工程与上下文管理。** 提示机制的设计与实施，在最大化基于大语言模型（LLM）的信息抽取流程效力方面起关键作用。

精心构建的提示充当控制参数，能够从研究文献中进行结构化抽取、标准化格式化和检索相关科学信息。一个用于数据抽取的提示示例如下：

“对于论文中识别出的每一种高熵合金 [X1X2...Xn]，确定存在的晶体学相。描述每一相的性质：非晶、固溶体、金属间化合物。如果可获得，请包括化学式、晶体学状态、结构和空间群。注意可能未在 X 射线衍射中可见、但在显微图中明显的任何析出物。”

在本方法中，我们采用迭代式思维链提示方法：在每次后续与 LLM 的交互中，都纳入此前所有交流的累积上下文：

$$
P_n = f(Q_n, \{(Q_1,R_1),(Q_2,R_2),..., (Q_{n-1},R_{n-1})\}) \tag{1}
$$

其中：

- $P_n$ 表示第 $n$ 个提示；
- $Q_n$ 是当前查询；
- $(Q_i,R_i)$ 表示第 $i$ 次交互中的问题–回答对；
- $f$ 是将当前查询与历史交互相结合的上下文聚合函数。

这种递归提示策略使模型在基于先前分析的同时保持上下文连续性，进而能够跨交互累积上下文信息。对对话历史的保存与使用可支持复杂材料科学概念及关系的解释，因为每个提示都从先前提示带来的上下文丰富化中受益。

实施遵循一套结构化流程：

- **初始上下文形成**：设计基础提示，以建立基本材料性质和关系；
- **迭代细化**：每个后续提示通过上下文窗口纳入先前回答；
- **回答验证**：自动验证回答格式和内容一致性。这可通过指定负责提供结构化输出的参数实现：在最终提示中，模型接收以嵌套 Python 类或 JSON 字典模式呈现的详细结构，作为请求参数之一。这样，模型必须以指定的半结构化格式返回数据；
- **上下文管理**：动态调整上下文窗口，以维持相关信息并避免词元限制。

为构建最终数据库 [22]，我们使用 5 个提示，每一个旨在识别分析中的一个不同关键组成部分。虽然已发布的 HEA 数据集 [22] 是本工作的主要结果，但 LLM 驱动的抽取方法使数据集能够以比人工整理更大的规模创建。
