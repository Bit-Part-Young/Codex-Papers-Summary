## 详细总结

### 1. 研究背景与核心问题

本文讨论的是面向机器学习原子间势的 SO(2) 理论与模型设计问题。作者指出，Clebsch-Gordan tensor product，CGTP 的计算代价较高，因此近年来出现了多种替代张量积形式，如 GTP、Matrix Tensor Product、SO(2) Linear、Cartesian tensor product、Wigner-6j convolution 和 VSTP 等。但在这些方案中，SO(2) 路线虽然在实践中采用最广，却仍存在若干未充分澄清的问题：

- 在相同角分辨率下，SO(2) 模型通常比 CGTP 路线具有更弱的外推能力和更低的精度；
- 现有 SO(2) 架构往往依赖边级非线性操作，导致实现复杂，也妨碍像 OpenEquivariance 或 CuEquivariance 这类面向 CGTP 的高性能融合库直接复用；
- 当前 SO(2) 路线中的精度提升，究竟来自 SO(2) 运算本身，还是来自边级非线性和更高的边体阶，仍需拆解；
- 复权重、局域参考系、径向信息和多体展开之间的关系，还缺乏系统的理论梳理。

作者因此试图回答三个层面的问题：第一，SO(2) Linear 与传统 SO(3) 张量积之间的真正对应关系是什么；第二，如何在 SO(2) 框架中构建更稳定、更高效、且兼具外推能力的多体交互模块；第三，这些方法能否在大规模材料基础模型训练中带来真实的基准性能提升。

### 2. 方法学贡献

#### 2.1 Wigner-D 矩阵构造

作者提出两种从旋转矩阵构造 Wigner-D 矩阵的方法：

1. 直接 Cartesian 构造。
2. 递归 Clebsch-Gordan 构造。

直接构造借助 irreducible Cartesian tensor decomposition，ICTD，在球张量与对称无迹 Cartesian 张量之间建立正交基变换；递归构造则利用路径矩阵本身可以通过 $1 \otimes (\ell - 1) \to \ell$ 的递归耦合产生，避免显式构造秩为 $\ell$ 的 Cartesian 中间张量。作者指出，直接方法数值稳定，但中间张量规模按 $3^\ell$ 增长；递归方法则把指数级增长替换为多项式级增长，并且避免了 eSCN 原始公式中的反三角函数与角奇点问题。

图 1 的运行时间对比显示，在从旋转矩阵或四元数构造 Wigner-D 的任务上，递归 Clebsch-Gordan 构造随 $\ell_{\max}$ 增大时具有更优的扩展性。作者还特别强调，与依赖超过 1000 行定制代码的 UMA 或 DPA4 不同，他们的方法可在不足 100 行代码中实现。

#### 2.2 uuSO2Linear 与 uvSO2Linear 的区分

作者认为，现有 SO(2) 架构普遍沿用了 eSCN 中的 SO(2) Linear，但它更接近一种“不依赖路径级径向权重”的全连接线性变换，因此作者将其记为 `uvSO2Linear`。相对地，作者把与传统 `uuu SO(3)` tensor product 更严格对应的形式记为 `uuSO2Linear`，并认为后者才是单层 SO(2) 算子替代 `uuu SO(3)` tensor product 的更合适候选。

这一判断的核心在于径向信息的使用方式。传统 SO(3) 路线中，径向信息与路径绑定；而在许多 SO(2) 模型里，径向项通常在 SO(2) Linear 之前通过实数乘法或复数乘法注入，因而并不直接作用到每一条 SO(2) 路径上。作者据此认为，很多已有 SO(2) 实现并不是严格意义上的对应替代，而只是另一个更灵活的、但约束更弱的线性模块。

#### 2.3 复权重与对称性约束

作者进一步分析了复值权重的作用。对复 SO(2) 特征 $x_m$ 施加复权重 $w = w_1 + i w_2$ 的确与旋转可交换，因此保持 SO(2) 等变；但在反射下，若 $w_2 \neq 0$，则该算子一般不满足 O(2) 等变。作者因此区分了三类权重：

- `w1`：仅保留实部，相位不变；
- `w1_w1`：实部与虚部相同，对应固定相位旋转加幅值变换；
- `w1_w2`：实部与虚部彼此独立。

作者的结论是，复相位并没有在本文考察的数据集上带来明显收益，反而常常削弱精度与外推能力。其根本原因是，复权重引入了训练数据未必能可靠约束的额外自由度。

#### 2.4 Edge Cluster Expansion，ECE

本文提出的核心模块之一是 ECE。作者把多体展开从传统的节点级 ACE 推进到边级，通过 generalized asymmetric contraction 在边上直接构造高阶交互。其动机有两点：

- Transformer 类架构在大规模预训练中已证明对显式建模源原子与目标原子关系是有利的；
- 若想在 SO(2) 局域参考系下引入边级多体交互，不能简单照搬全局 SO(3) 框架中的节点聚合再张量积做法。

作者先给出 generalized coupling coefficient 与 generalized asymmetric contraction 的一般形式，然后指出标准 symmetric contraction 有两个局限：

- 反复收缩同一个特征会导致不同多项式阶之间产生相关性，输出方差难以稳定控制；
- 它天然允许的计算路径更少，并会自动抹去 O(3) 下的反对称分量。

为解决这些问题，作者使用 ordered path 与多输入特征列表构造 product basis，并设计了更省显存的实现，避免显式物化高阶中间张量。作者指出，这种设计特别适合 ECE，因为边特征维数较小，而局域 SO(2) 表示的保留维数也远低于 Cartesian 表示。

#### 2.5 Angular Resolution、Body Order 与 RRA

作者用两类实验验证 ECE 的作用。第一类是 M 折旋转对称结构实验，用来检查模型是否能区分不同全局取向；第二类是来自 Pozdnyakov 等人的 2-body、3-body、4-body counterexample，用来检测模型是否真正提高了有效体阶。作者指出：

- 若先聚合再做 SO(2) ACE，则当 $m_{\max} < M$ 时，全局取向信息在聚合阶段就已消失；
- 若在聚合之前先做 SO(2) ECE，则复数乘法可以组合角频率，生成更高角阶项，从而恢复对全局取向的区分能力；
- 在边级设置下，`ECE + SO(2) Linear` 的流程能够逐步提升有效体阶，并成功区分更高体阶的几何反例。

在注意力机制方面，作者提出 Radial Rotary Complex Attention，RRA。该设计借鉴 RoPE 的思想，但强调几何图天然带有径向权重，因此注意力不仅应取决于节点相似性，也应显式依赖原子间距离。作者把 QK 相似度定义为复内积的实部，再引入仅依赖径向基的相位项、偏置项与可选温度项，用来控制不同注意力头的 softmax 灵敏度。

#### 2.6 Coupled ACE、残差与归一化

在 Coupled Atomic Cluster Expansion 部分，作者保留了 Cartesian TACE 中原有的 coupled ACE 思想，但做了两类改进：

- 用 `group linear + shared expert` 替代对所有通道进行稠密元素相关变换，以便在增加通道数时仍能保持可计算性；
- 用 scalar `0e` 特征参数化张量积权重，在不破坏多体结构的前提下引入 GLU 风格的额外非线性。

在网络结构设计上，作者强调第一层与后续层并不等价，因为第一层张量积的输入主要由标量 `0e` 特征与球谐组成。在他们的实验中，同时为 interaction module 和 product module 各自设置残差连接并非最佳；只保留一条主残差路径反而更稳定。归一化方面，作者采用 EquiformerV3 的 `EquivariantMergeLayerNorm`，但不在第一层和最终输出层后使用 LayerNorm，以避免抑制模型表达能力。

### 3. 实验设计与主要结果

#### 3.1 uuSO2Linear 的外推性优于 uvSO2Linear

表 1 给出了 3BPA 和 AcAc 上的外推结果。对于只含一层 SO(2) Linear 的 TACE：

- 在 3BPA 300 K 上，`uu` 的能量 / 力 RMSE 为 `3.7 / 8.8`，优于 `uv` 的 `4.7 / 11.8`，也略优于 `cgtp` 的 `3.8 / 9.1`；
- 在 3BPA 600 K 上，`uu` 为 `9.1 / 20.5`，优于 `uv` 的 `15.2 / 27.5` 与 `cgtp` 的 `10.5 / 21.5`；
- 在 3BPA 1200 K 上，`uu` 为 `27.9 / 59.0`，优于 `uv` 的 `30.7 / 70.4`，并略优于 `cgtp` 的 `29.5 / 62.0`；
- 在 AcAc 300 K 和 600 K 上，`uu` 也均优于 `uv`，并与 `cgtp` 相当或略优。

作者据此认为，`uuSO2Linear` 在更有效利用径向信息后，可以同时获得与 `uuu SO(3)` tensor product 接近的精度和外推性能，而 `uvSO2Linear` 的表达力更弱。

#### 3.2 复值相位通常削弱外推

表 2 比较了三种注意力机制与三类 SO(2) 权重类型。总体最佳结果来自 `Radial Rotary Complex Attention + w1`：

- 3BPA 300 K：能量 / 力 RMSE 为 `3.6 / 8.3`；
- 600 K：`8.6 / 19.8`；
- 1200 K：`27.0 / 55.4`；
- dihedral：`10.2 / 15.1`。

同一注意力机制下，`w1_w2` 基本总是最差或接近最差；`w1_w1` 一般介于 `w1` 与 `w1_w2` 之间。作者据此认为，在该类 MLIP 任务中，显式引入可学习复相位并不带来稳定收益，而保持实值权重更能兼顾对称性约束、精度与外推性。

#### 3.3 ECE 的确提高了有效体阶

表 3 基于 2-body、3-body、4-body counterexample 进行测试。作者把达到 `100%` 准确率的情形记为成功区分两图，`50%` 代表无法区分。

- 没有 SO(2) Linear 的 ECE 无法区分任何 counterexample；
- 只有一层 SO(2) Linear、但没有 ECE 时，只能在某些设置下解决 2-body 反例，无法稳定提升到更高体阶；
- `ECE + 一层 SO(2) Linear` 在 `rotate + ν = 2` 时已经能同时解决 2-body 和 3-body 反例，在 `rotate + ν = 3` 时则能进一步解决 4-body 反例。

作者据此认为，ECE 不是形式上的附加模块，而是确实在模型中引入了更高阶的可辨识多体信息。

#### 3.4 Matbench Discovery 上达到 SOTA

作者在 OMat24、sAlex 和 MPtrj 上训练，并发布 TECE-OAM-RRA-1.0。表 4 显示，该模型在 Matbench Discovery 上达到最高的总体 CPS 分数 `0.908`，超过：

- EquFlashV2：`0.907`
- EquiformerV3+DeNS-OAM：`0.902`
- GRACE-3L-OAM-L：`0.900`
- PET-OAM-XL：`0.898`

在表 4 记录的三项关键指标中，作者特别指出他们的模型在其中两项上取得第一，在另一项上排第二，因此得到最高的 overall score。表 7 的完整榜单还给出该模型的 `Acc = 0.978`、`F1 = 0.929`、`DAF = 6.073`、`MAE = 0.018`、`R^2 = 0.871`、`κSRME = 0.093`、`RMSD = 0.058`，参数量为 `222M`。

#### 3.5 速度与训练代价

表 5 采用单张 NVIDIA A800 80GB PCIe GPU，配合 ASE 分子动力学仿真引擎测试速度。对于 384 个原子的体系：

- TECE-OAM-RRA-1.0：`144 ps/day`
- EquflashV2：`285 ps/day`
- EquiformerV3+DeNS-OAM：`92 ps/day`

当体系增大到 768 和 960 个原子时，TECE 仍可运行，但 EquiformerV3+DeNS-OAM 已出现 OOM；当体系继续增大到 1152 个原子时，TECE 也 OOM，而 EquflashV2 仍可达到 `210 ps/day`。作者因此给出的速度排序是：

`EquflashV2 > TECE-OAM-RRA-1.0 > EquiformerV3+DeNS-OAM`

附录 A 说明，TECE-OAM-RRA-1.0 的总训练成本约为 `7680` 个 NVIDIA H20 GPU-hours。不过作者强调，这一训练成本并不能直接代表 TACE / TECE 架构的内在计算效率，因为他们所用平台的多 GPU 扩展性较差，而且 CUDA 与 PyTorch 版本过旧，导致无法启用基于编译的加速，实际观察到的训练成本约比必要值高 `3` 倍。

### 4. 作者明确承认的局限与展望

作者在第 4 节重点讨论了二原子基准中的异常现象。他们指出：

- OAM 系列数据集中，当 O 或 F 与某些过渡金属组合时，由于 Hubbard U 处理不一致，会导致势能面出现不连续；
- OrbV3 也报告过 OMat24 的 rattle 子集会损害二原子基准表现；
- Matbench Discovery 的前三名模型，包括 TECE-OAM-RRA-1.0、EquFlashV2 和 EquiformerV3+DeNS-OAM，在二原子基准上反而都表现较差；
- 相比之下，拟合能力较低的 TACE-OAM-L、NequIP-OAM-XL 和 MACE-MPA-0 往往更稳健。

作者把这一现象归因为训练数据中的伪特征：当模型容量和拟合精度提升后，模型更容易把数据集特定的人为痕迹与非物理特征也一并拟合进去，从而削弱在二原子构型等外推区域的鲁棒性。

作者还指出了若干未来方向与局限：

- 单层 SO(2) Linear 的算子融合仍是重要的后续工作；
- 现有数据集存在冗余、DFT 参数设置不一致、Hubbard U 处理不当等问题；
- 他们在开发过程中得到的中间模型 TACE-OAM-L 曾因代码错误只使用了约 `20%` 的训练数据，但仍表现很强，这从侧面说明当前数据集可能存在较大冗余。

## 摘要翻译

本文对 SO(2) 理论在机器学习原子间势，MLIPs，中的应用进行了系统研究，并识别出传统 SO(2) Linear 架构相对于 SO(3) Clebsch-Gordan tensor product，CGTP，的局限性。在这些认识的基础上，我们提出了 Wigner D 矩阵的直接 Cartesian 构造与递归 Clebsch-Gordan 构造，并引入了两个新的交互构件。第一，我们提出了基于 Generalized Asymmetric Contraction 的 Edge Complex Product Basis，这是一种新的多体展开形式，能够通过复值等变乘法在边上直接构造高阶相互作用。第二，我们引入了 Radial Rotary Complex Attention，RRA，它增强了外推性能，并超过了现有的注意力向量形式。我们还对 Atomic Cluster Expansion 模块做了若干改进。在这些进展基础上，我们在 OMat24、sAlex 和 MPTrj 上训练模型，并提出 TECE-OAM-RRA-1.0，在 Matbench Discovery 上实现了最先进，SOTA，的性能。

## 引言翻译

等变机器学习原子间势，MLIPs，已经成为分子动力学模拟中不可或缺的工具。然而，Clebsch-Gordan tensor product，CGTP，的高计算成本促使研究者发展替代性的张量积形式，以降低计算复杂度。具有代表性的例子包括基于网格的 Gaunt Tensor Product，GTP（Luo 等，2024），它表现出一种路径合并性质，从而避免显式计算多条张量积路径。在这一公式的基础上，EquiformerV3（Liao 等，2026）进一步将非线性与多体相互作用（Batatia 等，2022）结合起来，形成了 SwiGLU-S2 架构。尽管 GTP 在计算上高效，但它天然排除了反对称相互作用，并引入了等变误差，不过这些局限似乎对实际拟合性能影响有限。Matrix Tensor Product（Unke 与 Maennel，2024）同样利用路径合并，并通过修改收缩方案来加速计算，为传统张量积提供了优雅而高效的简化形式。通过显式地把特征旋转到与边对齐的局域参考系中，SO(2) Linear 框架不仅为 CGTP 操作提供了一种稀疏实现，而且引入了一类本质上不同于传统张量积的新型等变算子。这一路线表现出更好的扩展行为，并能以相对较低的计算代价在边上执行额外操作。相较之下，不可约 Cartesian 张量积与收缩（Xu 等，2026b；2026a）直接在 Cartesian 空间中执行等变卷积，并在低角阶下展示了有利的效率-精度折中。Wigner-6j Convolutions（Li 等，2026b）则进一步最大化了把边操作融合到节点级计算中的程度，从而实现高度节省内存的卷积。最后，Vector Spherical Tensor Product，VSTP，方法（Xie 等，2026；Heyraud 等，2026）把 vector spherical harmonics 与张量信号结合起来，用于处理基于网格方法中缺失的反对称相互作用。

在这些新兴的张量积形式中，SO(2) 理论已经成为实践中最广泛采用的路线。然而，人们对 SO(2) 方法的理论理解仍不完整。特别是，人们经常观察到，在相同的角分辨率下，基于 SO(2) 的模型相比基于 CGTP 的方法，外推性和精度都更低。然而，建立在 SO(2) 算子之上的模型在 universal MLIP，uMLIP，基准上却表现出更高的精度和更快的收敛。尽管从原理上说，SO(2) Linear 具有更优的渐近扩展行为，但这并不必然意味着它在实践中就是更优选择。除了上述局限之外，实际实现通常还需要两个 SO(2) Linear 操作以及施加在边级上的非线性变换。对这些复杂边级操作的依赖，使得难以发展出类似 OpenEquivariance（Bharadwaj 等，2025）和 CuEquivariance（NVIDIA，2024）那样高度优化的、通用的边融合库，而后者已经可用于基于 CGTP 的模型。在我们看来，uMLIP 上观察到的有限精度增益，并不足以证明这种额外的实现复杂性和因边级非线性所损失的融合机会是合理的。反过来说，如果去掉这些边级非线性操作，SO(2) Linear 的优势就基本消失了，这时人们完全可以直接使用 CGTP，而无需再引入 SO(2) 算子的额外复杂性。正如我们将在后续实验中展示的，较弱的外推能力主要来自模型设计选择，而不是来自 SO(2) 操作本身。特别是，对径向信息进行恰当处理，可以在不损害外推性能的前提下，显著拓宽模型设计空间。相反，在 uMLIP 基准上观察到的精度提升，在很大程度上可以归因于边级非线性与更高的边体阶。在本文中，我们重新审视了 SO(2) 等变性的复值本质。基于这一视角，我们分析复值表示下可学习权重的设计原则与约束，并刻画保持 SO(2) 等变性的操作类型。

在实验部分中，我们首先通过利用球张量与不可约 Cartesian 张量之间的关系，引入了一种更快且数值上更稳定的 Wigner-D 矩阵构造方法。接着，我们比较了 uuSO(2) Linear 与 uvSO(2) Linear 的行为，识别出各自表现优势与局限的适用区域。然后，我们考察 SO(2) Linear 算子中复值权重参数化的影响，研究三种代表性方案：`w1`、`w1_w1` 和 `w1_w2`。在 SO(2) Tensor Product，即复值等变乘法，的基础上，我们引入了一个 edge cluster expansion，ECE，模块，用于直接在边上进行多体展开。在这一部分中，我们还通过 M 折旋转对称结构（Joshi 等，2023）与 k-body counterexample（Pozdnyakov 等，2020）实验，进一步展示 ECE 与 SO(2) 操作的优势。此外，我们说明了如何利用复共轭乘法，从 query 与 key 表示构造一个 SO(2) 不变量，`m = 0` 的复值量，这自然导向了 Radial Rotary Attention 的形式。最后，我们通过 Matbench Discovery 基准（Riebesell 等，2025）上的实验，对这些设计进行了评估。

## 方法翻译

说明：原文没有单独的 “Methods” 章节。以下内容严格翻译自与方法最对应的结构部分：`2.1 SO(3) Irreps ↔ SO(2) Irreps`、`2.2 SO(2) Operations`、`2.3 Special Cases of Node-wise SO(2) Operations`，以及 `3.2` 至 `3.10` 中对所提方法的定义性段落。

### 来自 `2.1. SO(3) Irreps ↔ SO(2) Irreps`

与机器学习中 SO(3) / O(3) 操作相关的理论框架，最早是在 e3nn 中被系统实现的（Thomas 等，2018；Weiler 等，2018；Kondor 等，2018）。具体而言，SO(3) 的一个不可约表示由角阶 $\ell$ 与阶数 $m$ 索引，而可学习特征可以表示为一个维度为 $2\ell + 1$ 的张量。在机器学习应用中，通常还会引入额外的通道维度 $c$。因此，一个完整的 SO(3) 不可约表示可由 $(c, \ell, m)$ 索引。在一般情况下，不同的 $\ell$ 可以对应不同数量的通道；不过在本文中，我们不显式区分这一点。

与 SO(2) 相关的表示概念最早是在 eSCN 中引入的（Passaro 与 Zitnick，2023），作者在那里定义了 SO(2) Linear 操作。随后，QHNetV2（Yu 等，2026）进一步发展了用于 Hamiltonian 预测任务的 SO(2) 理论框架，并引入了 SO(2) Tensor Product 与 SO(2) Gate 等操作。描述平面旋转的 SO(2) 群是交换群。因此，在复数域上，它的所有不可约表示都是 1 维的。对 SO(2) 特征来说，旋转角度为 θ 的群作用可表示为把特征乘以单位复数 $e^{im\theta}$，其中 $m \in \mathbb{Z}$。

在几何图神经网络中，对于边级 SO(3) 特征，如果把所有边都旋转到一个共同的参考方向，并对特征施加相应的 Wigner-D 变换，那么旋转自由度就会降为一个剩余角度。在这种情况下，特征可以被视为局域 SO(2) 特征，从而允许我们施加与 SO(2) 相关的操作。类似地，通过施加 Wigner-D 矩阵的转置，也可以把这些特征再变换回去。

### 来自 `2.2. SO(2) Operations`

一般来说，复值 SO(2) 特征是通过把实值 SO(3) 特征旋转得到的。然而，对 SO(2) 特征的操作从复数视角来理解会更加自然。在本文中，所有 SO(3) 特征都在实值表示下处理，而所有 SO(2) 特征都在复值表示下解释。在实践中，我们可以使用 `torch.view_as_complex` 和 `torch.view_as_real` 在实值特征与复值特征之间转换。

给定复值权重 $w = w_1 + i w_2$ 和复值特征 $x_m = x_m^+ + i x_m^-$，复乘法 $w \cdot x_m$ 与旋转可交换，因此是 SO(2)-等变的。这意味着我们同时调制了复值特征的幅值与相位。特别地，如果施加约束 $w_1 = w_2$，则意味着我们只施加一个固定相位旋转，同时允许任意幅值变换。如果施加约束 $w_2 = 0$，则该操作只调制幅值而保持相位不变。我们把这三种针对复值特征的加权方式分别称作 `w1_w2`、`w1_w1` 和 `w1`。

一旦理解了复值权重的嵌入机制，SO(2) Linear 操作的本质就变得很清楚：它是在复域中，对具有相同阶数 $m$ 的不同通道 $c$ 和不同角阶 $\ell$ 的特征进行混合。该操作允许我们把更高角分辨率的信息标量化，也就是从 $(\ell > 0, m = 0)$ 变换到 $(\ell = 0, m = 0)$，从而获得与 SO(3) tensor product 类似的效果。

对于 SO(2) Tensor Product，给定两个复值 SO(2) 特征 $x_{m_1}$ 和 $x_{m_2}$，当 $m_3 = m_1 + m_2$ 或 $m_3 = m_1 - m_2$ 时，它们的复乘法在旋转下仍保持等变。因此，虽然某些已有工作把 SO(2) Linear 也称作 “tensor product”，但它实际上不同于 SO(2) Tensor Product。二者处理模型中的不同部分，并且都很重要。

### 来自 `2.3. Special Cases of Node-wise SO(2) Operations`

SO(2) 操作通常是在边上进行的，因为边方向天然提供了一个局域参考系。如果等价的操作可以直接施加在节点表示上，那么就有可能获得额外的计算节省。一条可能路线是 frame-averaging 方法（Lin 等，2024；Yu 等，2026），它们利用目标原子及其邻近的源原子构造一个局域参考轴。尽管这类方法在 Hamiltonian 预测任务中表现有效，但它们是否适用于原子间势还不清楚。选择某一个邻居可能会在局域原子环境发生变化时引入不连续性；而对所有邻居取平均虽然可以缓解这一问题，却会使形式在概念上重新接近把边操作汇总到节点层的方案，从而削弱原本希望获得的计算优势。

另一条路线源于简化 Wigner-6j Convolutions 的尝试（Huang 等，2026）。Wigner-6j Convolutions 利用 solid harmonics 和二项式展开来分离源原子和目标原子的角向依赖。由于 CGTP 的计算依然昂贵，由 solid harmonics 所允许的因子化表示自然会激发一种想法，即直接从原子位置构造局域参考轴。因此，尽管节点级 SO(2) 操作是一个很有前景的设计空间，但一种能够在不同架构间普遍适用的设计范式仍然缺失。

### 来自 `3.2. Cartesian Construction of Wigner-D Matrices`

球张量和 Cartesian 张量为三维等变特征提供了两种等价的描述。我们提出两种从旋转矩阵计算 Wigner-D 矩阵的方法。第一种方法更直观，也更容易理解；第二种方法则提供了更高效的实现。

在直接 Cartesian 构造中，irreducible Cartesian tensor decomposition，ICTD，提供了 degree-$\ell$ 球张量与 rank-$\ell$ 对称无迹 Cartesian 张量之间的正交基变换。通过在球基与 Cartesian 基之间插入 Cartesian 旋转，可以得到 Wigner-D 矩阵的直接构造式。尽管这种方法数值稳定，但它引入了一个包含 $3^\ell$ 个分量的 Cartesian 中间张量。当对一个包含 $E$ 条边的 batch 进行计算时，中间存储量按 $O(E 3^\ell (2\ell + 1))$ 增长。因此，随着 $\ell$ 增大，直接构造会迅速变得昂贵。

在递归 Clebsch-Gordan 构造中，我们注意到，路径矩阵本身可以通过 degree-one 表示与 degree-$(\ell - 1)$ 表示的耦合递归生成。这使我们能够避免显式 rank-$\ell$ Cartesian 张量。与直接构造相比，这一递归方法避免了指数级大的 Cartesian 表示，中间张量的规模转而表现为多项式增长；它同时具有更低的数值误差，并避开了原始 eSCN 公式中的反三角函数和角奇点。

### 来自 `3.4. uvSO2Linear and uuSO2Linear`

据我们所知，当前所有现有的 SO(2) 架构都采用了 eSCN 中引入的 SO(2) Linear。然而，考虑到该操作旨在替代带球谐函数的张量积，我们认为二者之间的对应关系并不完全直接。在传统 SO(3) 框架中，径向信息通常与来自 `uuu SO(3)` tensor product 的路径相关联，每条路径都拥有自身的路径依赖权重。相对地，在 SO(2) 框架中，径向信息通常是在 SO(2) Linear 操作之前，通过 SO(3) 实数乘法或 SO(2) 复数乘法被引入，而这些径向权重通常是实值的。因此，径向参数一般并不是直接为每一条 SO(2) 路径构造的。

因此，我们认为，eSCN 中引入的 SO(2) Linear 本质上是一种不依赖路径级径向权重的全连接线性变换。借用 SO(3) tensor product 中的命名习惯，我们把这种操作称为 `uvSO2Linear`。因此，我们认为，真正与 `uuu SO(3)` tensor product 对应的形式，应当是 `uuSO2Linear`。为了公平比较，我们在整个实验中只使用一层 SO(2) Linear 操作，并且不引入任何边级非线性。在这种设定下，我们比较两种形式在相同参数量下的性能。

### 来自 `3.5. Complex-Valued Weights Break O(2)/O(3) Equivariance and Weaken Extrapolation`

我们试图理解，为什么复值权重会出现在输入和输出都为实值的力场模型中。这自然引出了一个问题：复相位究竟提供了有意义的建模能力，还是仅仅引入了冗余自由度。以 `w1_w2` 为例，其复权重写作 $w = w_1 + i w_2$。在反射 $-I$ 下，复 SO(2) 特征 $x_m$ 会被映射为其共轭。因此，除非 $w_2 = 0$，否则变换前后的一般表达式并不相等。于是，`w1_w2` 一般只满足 SO(2) 等变，而实权重 `w1` 则与 O(2) 的反射对称性兼容。

这意味着，把模型约束为只使用实值权重，能够以构造的方式强制保证正确的对称行为。相反，一个 SO(3)-等变模型若不施加这一显式约束，就只能依赖训练数据去学习全局反演下的正确行为。在数据充分大且多样时，模型也许能近似学会这种性质；但在低数据区域，缺乏显式约束的问题会更加突出，并导致明显的性能差距。

### 来自 `3.6. Generalized Symmetric Contraction and Uncoupled Edge Cluster Expansion`

Transformer 架构已经在大语言模型中取得巨大成功。然而，我们对其直接用于机器学习原子间势仍然保持谨慎。原因主要有两点。第一，采用 Transformer 架构通常要求在边级显式执行复杂操作；对传统 CGTP 框架来说，这可能会很低效，并阻碍像 OpenEquivariance 或 CuEquivariance 这样成熟算子融合库的直接使用。第二，NequIP、MACE、EquFlash 和 TACE 等模型的成功表明，即便没有 graph softmax 机制，也已经可以取得强性能。

因此，我们通过 uncoupled edge cluster expansion，ECE，在边级引入多体相互作用。其关键思想是：利用 generalized coupling coefficient，直接对边特征执行张量收缩。标准的 symmetric contraction 反复收缩同一个特征，这会导致不同多项式阶之间的相关性增强，从而使输出方差难以直接归一化；与此同时，它允许的路径数更少，并天然抹去某些反对称贡献。为此，我们引入 generalized asymmetric contraction，使输入可以是一个特征张量列表，并按有序路径构造 product basis，再通过内部共享权重或外部依赖边 / 节点的权重对输出进行累积。

这一实现特别适合 ECE，因为它避免了显式构造完整高阶中间张量。作者还说明，ECE 允许边基只依赖源原子、只依赖目标原子，或者同时依赖两者。本文主要关注最后一种形式。

### 来自 `3.7. Angular Resolution and Body Order`

在这一小节中，我们分析 Edge Cluster Expansion 为什么能够提高角分辨率与体阶，以及它在这个意义上是否是完备的。具体来说，我们研究这些模块区分 M 折旋转对称结构的能力，以及它们能否提高表示的有效体阶。

在全局 SO(2) 参考系下，如果模型通过直接聚合邻居信息来构造中心原子的最终表示，那么当输入角分辨率满足 $m_{\max} < M$ 时，聚合后的信息将与全局取向无关；而如果在聚合前应用 SO(2) Edge Cluster Expansion，复数乘法就可以组合角频率并生成更高角阶项，从而得到依赖全局取向的表示。

在全局 SO(3) 参考系下，利用 2-body、3-body 和 4-body counterexample，可以展示 ECE 如何逐步构造更高体阶特征。对于基于 ACE 的架构，流程是 “卷积 → 聚合 → ACE → 节点读出”；而在边级设定下，需要使用 “卷积 → 聚合 → gather → rotate → ECE → SO(2) Linear → rotate back → 边读出”。在这个流程中，一旦在旋转后的局域参考系中施加 SO(2) Linear，更高阶分量中的标量信息就可以被混合进最终标量通道，从而使模型的有效体阶增加 1。

### 来自 `3.8. Radial Rotary Complex Attention`

我们认为，几何图天然带有径向信息。如果丢弃这些信息，而只依赖简单的 QK 内积或与注意力向量的收缩，模型的外推能力就可能受损。理想情况下，注意力应当同时依赖节点间的相似性以及它们的相对距离。受 Rotary Position Embeddings，RoPE，启发，我们提出了 Radial Rotary Complex Attention，RRA。考虑到 SO(2) 表示的复值本质，我们把 QK 相似度定义为复内积的实部，也就是 `0e` 分量。

特别地，我们引入径向相位、径向偏置以及温度项。这里，温度项用于控制不同注意力头 softmax 的敏感度。在实践中，我们通常设置 $\tau_{\min} = 0.25$、$\tau_{\max} = 4.0$。每个注意力头的权重是在节点 $i$ 的所有入边上计算的。同时，还引入了一个 envelope function，以改善 EquiformerV3 中报告的不连续性问题。

### 来自 `3.9. Coupled Atomic Cluster Expansion`

我们仍然采用在 Cartesian TACE 中使用的原始 coupled ACE 实现。所谓 “coupled”，是指在张量积之后，对所有通道施加元素相关权重以实现信息耦合。在实践中，只使用 `48 - 64` 个通道就足以达到与使用 `128 - 256` 个通道的 uncoupled 实现相当的精度。然而，它的局限也很明显。首先，元素相关参数化引入了大量权重。其次，当通道数超过 `64` 时，coupled 形式会导致不必要的计算和内存开销。

因此，我们主要从两个方面改进 ACE 实现。第一，我们让 coupled ACE 在提升通道维度时仍然可用。第二，我们在不破坏生成的多体结构前提下，引入额外非线性。为此，我们使用 `group linear + shared expert` 的形式，让每个元素相关 expert 只处理一部分通道，而元素无关的 shared expert 负责在所有通道之间耦合信息。

为了向 product basis 模块中引入附加非线性，同时不破坏其多体结构，我们采用了一种受 EquflashV2 启发的策略：利用标量 `0e` 特征参数化 tensor product 权重。线性投影首先产生两个非对称原子基，以及标量依赖的 ACE 系数；随后，第一阶相关项直接由节点特征给出，第二阶相关项则通过把这些特征与加上常数标量的 base 特征耦合得到。

### 来自 `3.10. Residual Network and Layer Norm`

在等变网络中，一个重要细节是：消息传递过程中的第一层与后续层不同。在第一层边级张量积操作中，张量积通常是由 `0e` 特征，例如元素嵌入，和球谐函数构成的。因此，在第一步消息传递之前，只有标量信息可用。在这种情况下，直接把 `0e` 特征视作残差连接通常并不理想。

我们进一步观察到，在没有 LayerNorm 的情况下，在 interaction module，A basis，和 product module，B basis，中分别独立使用两条残差连接，并不能在我们的框架中得到最佳性能；而且这一设计会对层数更加敏感，也更容易引起训练不稳定。相反，只使用一条残差路径时，通常能稳定获得更好的精度。与此同时，我们采用 EquiformerV3 中提出的 `EquivariantMergeLayerNorm`，因为这一归一化策略能够在保留不同 irreps 之间尺度差异的同时，提高训练稳定性。出于与残差设计相同的考虑，我们在第一层省略 LayerNorm，并且不在最后一层之后使用它。

## 结论翻译

说明：原文没有单独的 “Conclusion” 章节。以下内容严格翻译自 `4.1 Diatomic Benchmark` 末尾最接近结论的总结性段落，并补充其前一段中对局限性的概述。

我们还在二原子基准中观察到了一些有趣现象。广泛使用的 OAM 系列数据集，当 O 或 F 与某些过渡金属元素组合时，由于采用了不同的 Hubbard U 处理方式，其势能曲面会出现不连续。此外，OrbV3（Rhodes 等，2025）也报告说，OMat24 的 rattle 子集可能会对二原子基准上的性能产生不利影响。事实上，Matbench Discovery 上排名前三的模型，包括 TECE-OAM-RRA-1.0、EquFlashV2 和 EquiformerV3+DeNS-OAM，在这一二原子基准上都一致表现出相对较差的性能。相反，拟合能力较低的模型，例如 TACE-OAM-L、NequIP-OAM-XL 和 MACE-MPA-0，往往在这一基准上表现更好。我们认为，这种行为主要归因于训练数据本身的局限：随着模型容量和拟合精度的提高，模型更有可能把数据集特定的伪特征和非物理特征也一并拟合进去，从而降低其在二原子构型等情形下的鲁棒性。

总之，我们系统地回顾、整合并扩展了用于机器学习原子间势的 SO(2) 理论，同时验证了若干在实践中非常重要的实现细节。我们进一步引入了 Cartesian 的直接与递归 Wigner-D 构造、Edge Cluster Expansion，ECE，以及 Radial Rotary Complex Attention，RRA，并发布了一个建立在这些组件之上的最先进材料基础模型。我们的结果表明，本文提出的设计选择提供的是相互补充的收益，而不是一种普适的最优配置。当目标是在大规模预训练中追求最高精度时，结合边级非线性与 RRA 的 ECE 是最有效的策略。当主要关注内存效率时，uuSO2Linear 通常更可取，因为它具有更强的归纳偏置、表达能力以及与算子融合的兼容性。从架构角度看，一个重要的未来方向是针对单层 SO(2) Linear 算子的算子融合。在本工作过程中，我们还确认了现有数据集中的若干局限，包括数据冗余、DFT 参数设置不一致，以及对 Hubbard U 修正的不恰当处理。举例来说，在构建我们 SO(2) 模型家族的过程中开发的一个中间模型 TACE-OAM-L，由于一个代码错误，只使用了大约随机 `20%` 的训练数据进行训练。尽管训练数据大幅减少，它仍然表现出异常强的性能。
