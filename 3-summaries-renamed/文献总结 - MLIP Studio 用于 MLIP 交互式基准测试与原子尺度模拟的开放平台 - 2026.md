## 二、文献核心总结

### 1. 研究背景与问题

- 通用机器学习原子间势（universal MLIPs）正在快速替代部分传统第一性原理工作流，但实际使用仍受限于软件生态碎片化、依赖冲突、模型接口不统一，以及缺少便于比较不同模型的开放基准平台。
- 不同 MLIP 框架往往依赖彼此不兼容的 PyTorch、PyTorch Geometric、NumPy、e3nn 等版本，导致研究者必须维护多个虚拟环境，严重妨碍端到端对比测试与可重复工作流。
- 现有商用平台多为闭源且订阅成本高，而公开的、支持多家模型统一比较的交互式 MLIP 平台很少。

### 2. 文章的主要贡献

- 作者提出 MLIP Studio，一个免费、开放、可交互的 Web 平台，用于分子与材料体系上的 MLIP 驱动计算、模型比较与基准测试。
- 平台统一集成了超过 60 个通用 MLIP，覆盖 MACE、FairChem（UMA/eSEN）、ORB、MatterSim、SevenNet、PET 等主要模型家族，并同时支持半经验 GFN2-xTB、经典 UFF 和独立 D3 色散修正。
- 平台支持从结构导入、模型选择、任务设置到结果可视化的完整工作流，能够执行单点能/力/应力计算、原子化能/内聚能、几何优化、振动分析、状态方程拟合、自旋态判定、轨迹分析、自定义模型上传、电子性质预测与性能基准测试。
- 平台内置自动 parity plots、可排序误差表和墙钟时间记录，方便发现按元素分解的异常点、高误差帧以及不同模型的速度-精度权衡。

### 3. 平台架构与方法学特点

- MLIP Studio 采用 Streamlit 构建前端，以 Python 为后端，并调用 ASE 与 Py3Dmol 等库完成计算与三维结构可视化。
- 作者通过大量兼容性测试，将原本彼此不兼容的多套 MLIP 安装到统一环境中，使用户可在同一会话中即时切换 60 余个模型进行公平对比。
- 平台支持多种结构输入方式，包括示例结构、本地文件、文本粘贴、Materials Project ID、PubChem、批量上传以及 extXYZ 轨迹上传。
- 为几何优化，平台除 ASE 现有优化器外，还实现了自定义 Fast-MSO 多阶段优化器，以 FIRE → MDMin → LBFGS 的固定顺序逐步降低残余力并提升收敛稳定性。

### 4. 主要结果

- MLIP 预优化显著降低后续 DFT 几何优化成本：对 ibuprofen、caffeine 与 $(\mathrm{H_2O})_{64}$ 三个案例，作者报告的加速倍数约为 $5\times$ 到 $33\times$。
- 对 1000 个随机打包的 $(\mathrm{H_2O})_{64}$ 构型，不同 PBE 水平训练的通用 MLIP 给出定性一致的势能曲线，并一致识别最高能与最低能构型，说明跨模型构型筛选具有一定稳健性。
- 对 500 帧 CrCl3 /sapphire AIMD 轨迹，PET OMAT v1 M 在相对能量误差上最佳，而 UMA OMAT s1p1 在力误差上最佳，表明“最佳 MLIP”取决于目标物理量。
- CPU 与 GPU 基准表明不同模型速度差异可超过一个数量级，且 CPU 与 GPU 上的相对速度排名会发生变化。

### 5. 典型案例结论

- 作者以 CrCl3 在蓝宝石（α-Al2O3）表面上的吸附为案例，串联展示了体相验证、自旋态判定、表面能评估、倾斜二聚体旋转势能曲线比较以及 AIMD 参考轨迹基准测试。
- 该案例强调：模型选择必须面向具体任务与具体物理量，而不是只看统一误差指标。

### 6. 文章局限与展望（基于原文）

- 原文指出平台未来将扩展到分子动力学（NVT/NPT/NVE）、NEB 路径搜索、纳米团簇全局优化以及多任务自动串联工作流。
- 作者同时强调平台的插件化结构可持续接纳快速涌现的新 MLIP 架构与数据集。

## 三、摘要翻译

通用机器学习原子间势（MLIPs）是正在改变原子尺度模拟的基础 AI 模型，但它们的实际使用仍然受到碎片化软件生态、依赖冲突以及缺乏易用基准测试工具的阻碍。这些模型能够以远低于第一性原理密度泛函理论（DFT）计算成本的代价，接近 DFT 精度。我们介绍 MLIP Studio（可在 https://mlipstudio.iisc.ac.in 获取），这是一个开放且免费的平台，可将 60 多个通用 MLIP 集成到面向分子与材料的统一交互式界面中。该平台支持端到端的 MLIP 驱动工作流，包括性质预测、几何优化、振动分析、状态方程分析、自旋态判定、自定义模型部署，以及相对于参考数据的高通量基准测试。自动生成的 parity 图和可排序误差表能够帮助快速识别按元素划分的离群点与存在问题的数据点。我们证明，基于 MLIP 的预优化可将后续 DFT 优化工作量降低约 $33\times$。

此外，该应用还支持计算性能基准测试。通过一个涉及二维磁性材料 CrCl3 在蓝宝石基底上的综合案例研究，我们展示了不同性质与势能曲面在跨模型比较中如何帮助进行面向任务的 MLIP 选择。总体而言，MLIP Studio 降低了在计算化学与材料科学中将基础模型可靠地用于端到端研究工作流、基准测试与教学的门槛。

## 四、引言翻译

机器学习原子间势（MLIPs）是用于逼近量子力学势能面的数据驱动模型 [1-3]。与依赖固定函数形式且灵活性有限的经验势场不同，MLIP 采用灵活的神经网络架构，因此能够系统地逼近其训练目标量子力学方法的精度。量子力学密度泛函理论（DFT）计算是现代计算材料科学的主力工具 [4-8]。尽管 DFT 具有很高精度，但其高昂的计算成本 [9-13] 推动了 MLIP 的发展；这类模型将接近从头算的精度与数个数量级的计算加速结合起来。近年来，已经出现了多种可应用于广泛化学体系的通用型或基础型 MLIP，涵盖从简单分子到复杂固体 [14-22]。通用 MLIP 是在包含数百万数据点、具有化学多样性的 DFT 数据集上预训练的大规模原子间模型，目标是在无需针对特定体系重新训练的情况下，对分子、固体和界面实现具有可迁移性的零样本精度。通用 MLIP 这一蓬勃发展的研究方向，正在迅速改变化学与材料科学中的原子尺度模拟 [14]。

尽管架构创新发展迅速，MLIP 生态仍然分散在彼此独立的软件栈、互不兼容的库依赖以及异质化接口之中。因此，对不同研究团队开发的模型进行系统基准测试和可重复比较，在技术上仍然极具挑战性。此外，虽然已经存在若干用于量子力学或经典分子计算的交互式应用，例如 TMoleX [23]、GaussView [24]、BURAI [25]、Quantum ATK [26] 和 Avogadro [27]，但面向 MLIP 的同类平台仍基本缺失，这限制了通用 MLIP 在教学培训与快速原型开发中的可达性。MLIP Studio 旨在解决这些问题，它提供一个免费、源码可用且完全交互式的界面，使用户能够上传或导入任意化学结构，并从 60 多个通用 MLIP 模型中进行选择，以执行多种计算，包括能量、力、应力、带隙和偶极矩预测，几何优化，振动分析，以及体模量、内聚能和原子化能的评估，而且所有这些都在一个无缝集成的环境中完成。

MLIP Studio 的基础在于“可访问科学软件”的理念，这一理念在更广泛的材料信息学社区中正日益受到重视 [28-30]。一些近期项目，例如 MLIP Arena [31] 和 MatBench Discovery [32]，已经表明在 MLIP 基准测试中考虑物理一致性、可迁移性和真实应用场景的评估，对公平性和透明性至关重要。与此同时，基于 Streamlit [33] 等现代框架构建的大量交互式 Web 应用也已在从药物发现到材料性质预测等不同领域中涌现出来。例如，Materials Project 的 Web 应用 [29,30,34] 提供可检索的晶体结构数据库及其计算热力学与电子性质，并配备 API 与可视化工具。类似地，C2DB [35] 提供面向二维材料的数据探索与可视化平台，而 Materials Cloud [36] 则提供精选数据集、交互式结构查看器和可复现的计算工作流。总体来看，这些基于 Web 的平台使材料数据及相关工具更容易被访问和分析。尽管取得了这些显著进展，能够提供全面 MLIP 导向工作流并同时支持多个研究团队模型的免费平台仍然非常少。现有多数解决方案是专有商业服务，如 RowanSci [37]、Quantistry [38]、Matlantis [39] 和 QpiAI [40]，它们依赖闭源实现并具有较高订阅成本。

MLIP Studio 正是为填补这一空白而设计，它利用可自由获取的工具，提供一个通用且可扩展的、基于 Web 的 MLIP 评估与 MLIP 驱动原子尺度模拟框架。MLIP Studio 在同一计算环境中提供来自 5 个主要模型家族的 62 个通用 MLIP：multi-atomic cluster expansion（MACE）[20]、FairChem [17]、MatterSim [18]、orbital materials（ORB）[15,16]、SevenNet [21] 以及 point-edge transformer（PET）[41,42]。该 Web 应用使用 Streamlit [33] 构建，这是一个以 Python 为基础的框架，以其快速原型能力以及与 Atomic Simulation Environment（ASE）[43] 和 Py3Dmol [44] 等强大后端库便捷集成而闻名，后者支持分子结构的交互式三维可视化。这个易于使用的图形用户界面（GUI）确保了即使编程经验有限的研究者也能使用 MLIP 驱动的原子尺度模拟。后端采用 Python 还确保了底层架构的模块化与可扩展性，并能良好兼容现有多样的数据集、材料信息学库和 MLIP 框架生态。因此，用户可以在不同 MLIP 模型之间无缝切换，并直接比较它们在自己数据集上的表现，而无需编写任何代码。

与收取许可费用且 MLIP 选择有限的商业替代方案不同，MLIP Studio 完全免费，并采用 Academic Software License（ASL）发布。完整源代码可从其 GitHub 仓库 [45] 获取。此外，我们还在自有服务器上部署了一个专用实例，地址为 https://mlipstudio.iisc.ac.in，并提供 GPU 加速，以便为社区提供稳定且持久的演示访问点（在线免费版本对体系规模有所限制）。不过，用户也可以克隆仓库并在本地机器上运行，以绕过这些限制。这种对开放性的坚持促进了可重复性、社区驱动开发以及在不断增长的通用 MLIP 生态中进行透明基准测试。

除许可与可达性问题外，MLIP 采纳的一个重要实际障碍在于：很难在单一计算环境中安装并管理多个 MLIP 框架。来自 FAIRChem [17,19]、MACE [20] 和 ORB [15,16] 的常用 MLIP 包往往依赖于特定且彼此不兼容的核心库版本，如 PyTorch、PyTorch Geometric、NumPy 或 e3nn [46]。在实践中，这意味着希望比较多个 MLIP 预测结果的研究者必须为每个模型维护独立虚拟环境，并在每次新计算时切换环境，这一过程既繁琐，又不利于建立用于系统基准测试的无缝工作流。MLIP Studio 通过提供一个经过精心整理的统一环境来消除这一摩擦，在该环境中，所有支持的 MLIP 都安装为彼此兼容的库版本。为实现这一点，作者进行了广泛的兼容性测试，系统识别出一组库版本；这些版本虽然不总是与各软件包默认依赖文件中的指定版本一致，但仍能在所有支持模型上产生正确且经过验证的结果。因此，用户可以在同一会话中即时切换 60 多个模型，而无需担心依赖冲突或环境管理问题，从而实现原本需要大量准备工作的无缝且公平的并列比较。

该平台的模块化、插件式架构旨在适应 MLIP 快速发展的节奏。新的模型、模拟协议和后处理工具都可以以较小工作量集成进来，从而确保 MLIP Studio 能够随着 MAD [47-49]、OMAT24 [50]、OMOL25 [51]、MaPES [52] 和 MPTraj [29,30,34] 等新方法和数据集的不断出现而保持更新。通过在同一平台支持 60 多个、跨越不同架构家族的 MLIP，平台不仅能进行标准误差指标的并列比较，还能根据用户自己的数据集，对物理一致性、稳定性与可迁移性进行评估。

此外，用户体验与可达性也是 MLIP Studio 开发中的关键设计准则。作者认识到，再健壮的计算工具，如果可用性不足，也难以发挥效果。因此，该 Web 应用被设计为尽可能降低最终用户的学习门槛。拖放式文件上传界面与直观的模拟协议、MLIP 模型选择菜单相结合，使得即使计算背景有限的用户，也能够利用通用 MLIP 的能力来探索复杂化学现象。因此，MLIP Studio 不仅适用于研究工作流，也可作为教学平台。通过提供几何优化轨迹、振动光谱、状态方程拟合和自旋扫描的实时可视化，该应用使用户无需编写代码即可交互式理解原子尺度模拟中的核心概念。这使得该平台适合用于课堂演示和研究生阶段的计算化学与材料科学课程。

除了提高可达性并统一多样化 MLIP 框架之外，MLIP Studio 还特别强调实际工作流与模型评估。它支持基于 MLIP 的几何预优化，可获得接近 DFT 极小值的结构，从而显著降低后续第一性原理优化成本。平台还支持对构型系综进行快速筛选，其中能量剖面与可下载数据使得识别最低能结构并开展后续模拟变得直接明了。当存在参考数据时，自动生成的 parity 图和可排序误差表能够帮助识别高误差构型，并高效诊断存在问题的训练帧。所有计算都会报告墙钟时间，从而支持跨硬件系统地比较模型性能。平台还支持自旋态判定，为 DFT 计算提供有用的初始猜测。此外，它还便于比较不同 MLIP 所生成的势能面。

### 5.1 第 2 节：MLIP Studio 支持的通用机器学习原子间势

MLIP 学习的是从原子序数与笛卡尔坐标到目标量子力学可观测量之间的映射。通常，主要目标是势能面。在守恒形式中，力通过预测势能对坐标的负梯度得到；在直接力形式中，力被直接预测（不经过求导），以提高吞吐量并降低内存占用。除能量和力外，MLIP 还可以被训练来预测偶极矩、带隙、分电荷、态密度（DOS）等性质 [49]。大多数研究组为特定问题开发的 MLIP 都是定制型的：它们针对特定材料、相或反应路径训练，并在受限化学空间内优化精度。在分布发生偏移时，它们的预测可靠性通常会下降，需要在遇到新环境时重新训练或采用主动学习。通用或基础型 MLIP 追求的是不同的目标。它们在包含数百万量子力学 DFT 计算、具有化学多样性的数据集上进行预训练，目标是在广阔化学空间中无需针对特定体系重新训练就具有可迁移精度。从这个意义上说，通用 MLIP 可以视为一个预训练基础模型，能够以零样本方式直接部署，或针对下游任务进行微调。

从架构角度看，大多数现代 MLIP 都属于几何图神经网络（GNN）[14]。在这一表述中，一个原子构型被表示为图：节点对应原子，边连接有限径向截断半径内的相邻原子。消息传递层通过聚合邻居原子的信息，迭代更新原子特征向量，从而构造局域化学环境的多体表示。径向截断定义了模型中所包含相互作用的空间范围，并通过将计算限制在局域邻域中，确保系统尺寸上的线性标度 [53]。

物理对称性对 MLIP 的预测施加了额外约束。预测总势能必须对整体平移、整体旋转与原子置换保持不变，而力则必须在旋转下满足协变性 [53]。最先进的 MLIP 通常通过两类方式来满足这些对称性：一类是显式地采用协变张量表示 [20,22]，利用球谐函数与 Clebsch-Gordan 系数表示并更新原子环境（例如 MACE [20] 与 NequIP [46]）；另一类则通过数据增强与正则化（equigrad）来隐式满足这些约束 [15]。关于几何 GNN 架构、对称性处理、张量表示及其数学基础的系统解释，作者建议读者参阅文献 [53] 中的详细综述。

在这一背景下，已经出现了若干通用 MLIP 架构家族，它们在对称性处理方式、模型容量扩展方式以及计算效率优化方式上存在差异。文中简要总结了 MLIP Studio 支持的主要模型家族及其关键设计选择。

- MACE：MACE 引入了高阶协变消息传递，使得每个相互作用模块内部都能捕捉多体关联，并建立在 atomic cluster expansion（ACE）表述之上 [54]。通过提升体阶而非增加网络深度，MACE 能够在仅使用少量层数的情况下获得较高表达能力，从而改善数据效率与并行可扩展性。其采用不可约球张量特征，从而保证严格的 E(3) 协变性，同时相较于早期张量场网络控制了参数增长 [20]。
- ORB：ORBv3 家族通过同时提供守恒模型（通过 equigrad 正则化施加旋转不变性）和轻量级直接力模型，构成了性能-速度-内存的 Pareto 前沿。后者相对于传统 MLIP 可实现约 $10\times$ 的延迟降低与约 $8\times$ 的内存降低，从而支持超过 100000 个原子的稳定分子动力学 [15]。
- UMA（FAIRChem）：UMA 家族基于 equivariant smooth energy network（eSEN）架构，并利用 mixture of linear experts（MoLE）机制扩展模型容量。原文强调该家族以大规模数据训练，并面向通用零样本预测。
- MatterSim、SevenNet 与 PET：这些模型分别在多元素、多温压条件、并行可扩展性以及基于 transformer 的边消息传递设计方面做出不同取舍。PET 特别强调不通过球张量代数显式施加 E(3) 对称性，而是通过数据增强学习近似不变/协变性，并兼顾较低推理成本与有竞争力的精度-效率权衡。

原文在表 1 中列出了平台所支持的通用 MLIP 清单，按家族组织，包括 MACE、FAIRChem（UMA/ESEN）、ORB v3、MatterSim、SevenNet 与 PET 多个分支及其具体模型变体。作者借此说明：MLIP Studio 的方法学重点并不是提出新的单一 MLIP，而是把多家族模型纳入统一界面与统一环境中，方便横向对比。

MLIP Studio Web 应用围绕一个精简的四步工作流进行设计：(i) 结构输入；(ii) 模型选择；(iii) 任务配置；(iv) 执行与输出可视化。图 1 给出了首页的带注释总览，突出展示了这四个阶段。

#### 5.3.1 结构输入

该应用支持多种输入方式，如图 1a 所示。用户可从以下方式中选择：

- 选择示例：平台提供预定义示例结构，使用户无需准备输入文件即可快速体验应用。
- 上传文件：用户可从本地设备上传结构文件。支持的格式包括 CIF、extXYZ、XYZ、POSCAR、TURBOMOLE 和 MOL。
- 粘贴内容：用户也可以不上传文件，而是将任意支持格式的结构文件内容直接粘贴到文本框中。
- Materials Project ID：通过指定 Materials Project 标识符（mp-id），可直接从 Materials Project 数据库 [30] 导入晶体结构。
- PubChem：通过分子名称或化学式，可从 PubChem 数据库 [61-64] 导入分子结构。
- 批量上传：可以同时上传多个结构文件，格式可任意混合，用于批处理。
- extXYZ 轨迹上传：可以上传包含多个帧或多个构型的扩展 XYZ 轨迹文件，以便顺序评估。

当通过上述任意方式提供结构后，平台会对其进行解析，并如图 1c 所示，利用 Py3Dmol [44] 在交互式三维查看器中渲染。用户可以旋转、缩放并检查结构，还可以在球棍模型、棍模型或空间填充模型等不同显示风格之间进行切换。

#### 5.3.2 模型选择

模型选择面板如图 1b 所示，允许用户从前面介绍的五大 MLIP 家族中选择模型，也支持半经验计算器 GFN2-xTB [65]、经典计算器 UFF [66] 以及独立的 D3 色散修正计算器 [67]。单独提供色散修正计算器非常有用，因为并非所有模型都支持范德华色散修正选项；借助这一功能，即使模型本身不支持，也可以在之后附加色散修正。选定某个模型家族后，用户可以进一步选择该家族内的具体模型。对于 MACE 架构模型，用户还可以通过上传模型文件或提供模型下载 URL 的方式引入自定义模型，从而在同一界面中使用已经微调过的模型或仍在开发中的模型。

#### 5.3.3 计算设置与执行

计算设置面板如图 1d 所示，在执行前总结当前配置。它显示所选模型类型（例如 MACE）、具体模型名称（例如 MACE MPA Medium）、是否启用了色散修正（适用于支持 D3 修正 [68] 的 MACE 模型），以及计算设备（CPU 或 CUDA，若存在兼容 GPU）。该面板还会显示当前选择的计算任务。所有参数设置完成后，用户点击 “Run Calculation” 按钮即可启动计算。计算完成后，结果将直接在浏览器中显示，具体形式见第 4 节。

### 5.4 第 4 节中与方法实现直接相关的关键内容

#### 5.4.1 几何优化

几何优化用于弛豫原子坐标（对周期体系还可选地弛豫晶胞），以最小化总势能。MLIP Studio 提供一系列由 ASE [43] 支持的优化器，包括 LBFGS [69]、BFGS [70-73]、LBFGSLineSearch [74]、BFGSLineSearch [74]、FIRE [75]、GPMin [76] 和 MDMin。用户可在界面中指定最大优化步数与力收敛判据（单位 eV/Å），如图 2c 所示。

在优化过程中，应用会实时显示每一步迭代的能量与最大力表格。收敛后，平台给出：(i) 最终优化能量与最大残余力；(ii) 总步数与是否达到收敛；(iii) 经过交互式可视化的优化后结构；(iv) 可下载的逐步能量与力表；(v) 能量随优化循环变化的曲线；(vi) 可查看和下载的完整优化轨迹。作者指出，这些输出也使 MLIP Studio 成为讲授几何优化概念、比较不同优化算法行为的有价值教学工具。

除标准 ASE 优化器外，作者还实现了一个自定义的多阶段优化器 Fast-MSO（Fast Multi-Stage Optimizer），按照固定、单调的顺序串联三个优化器：FIRE → MDMin → LBFGS。其设计动机是：FIRE 适合处理残余力较大的构型，MDMin 在中等力范围内具有较高的下坡弛豫效率，而 LBFGS 在接近极小值时能够快速收敛。当最大力（绝对值）低于用户可配置阈值 $f_{\mathrm{FIRE}}$ 和 $f_{\mathrm{MDMin}}$ 时，优化阶段发生切换，默认值分别为 0.8 和 0.25 eV/Å。每次切换后，新的优化器都会重新初始化，以避免前一优化器累积的内部状态（例如 Hessian 近似或速度向量）造成污染。一旦发生阶段切换，即使未来某一步最大力重新上升，也不会回退到前一优化器，以保证可重复行为。

#### 5.4.2 振动分析

振动模分析通过对力进行有限差分近似来计算结构的正则模频率。计算完成后，平台会输出全部振动模频率表（单位 cm$^{-1}$）及其分类（物理模或低频平移/转动模）、频率分布直方图、用户指定温度下的零点振动能（ZPE），以及可下载的振动数据 CSV 文件。作者指出，该功能特别适合判断驻点是过渡态还是局域极小值。

#### 5.4.3 状态方程

状态方程（EOS）任务允许用户对周期体系计算能量-体积关系并提取力学性质。用户指定体积采样点数、相对于平衡体积的体积变化范围，并在 Birch-Murnaghan [92]、Murnaghan [93] 与 Vinet [94] 状态方程之间选择拟合形式。平台对晶胞做均匀缩放，在每个体积点用选定的 MLIP 计算能量，并将得到的 $E(V)$ 数据用于所选 EOS 拟合。输出包括体模量 $B_0$、其压强导数 $B'_0$、平衡体积 $V_0$、平衡能量 $E_0$ 及相应拟合不确定性，同时提供可下载的数据表和拟合曲线。

#### 5.4.4 自旋态判定

自旋态判定任务利用某些包含自旋与电荷信息训练的 MLIP（尤其是 UMA OMOL 家族）接受自旋多重度和电荷作为输入参数的能力。平台通过扫描给定分子的不同自旋多重度（即未成对电子数），以总能量最低的构型作为基态自旋。这可以直接为后续 VASP DFT 计算提供更好的 MAGMOM 或 NUPDOWN 初始猜测。

#### 5.4.5 批处理与轨迹分析

MLIP Studio 提供两种紧密相关的批量处理模式：批量上传器和 extXYZ 轨迹上传器。前者用于同时上传多个结构并汇总各构型的能量、最大力与应力；后者对多帧 extXYZ 文件逐帧评估，并支持两类典型用途：

- 势能面筛选：快速比较大量随机初始构型的相对稳定性，提取最低能构型。
- 相对于参考数据的基准测试：若 extXYZ 中包含参考能量、力或应力，则自动生成 parity 图并输出 MAE、RMSE 和 $R^2$ 等误差指标，还能按元素颜色区分力误差来源。

#### 5.4.6 自定义模型上传与性能基准

平台支持上传自定义 MACE 模型或通过 URL 下载自定义模型，并将其直接纳入所有现有推理任务中。作者认为，这对模型开发中的快速诊断与可视化比较非常有用。

所有计算均报告墙钟时间，因此可以直接进行 MLIP 推理速度基准测试。作者用 1000 个 $(\mathrm{H_2O})_{64}$ 构型比较了代表性模型在 CPU 与 GPU 上的能量、力、应力推理速度，并强调不同硬件上的相对性能排序并不相同。

## 六、结论翻译

在这项工作中，我们提出了 MLIP Studio，这是一个免费的基于 Web 的平台，为 60 多个通用机器学习原子间势提供统一访问接口，这些模型横跨六个主要模型家族，包括 MACE、FairChem（UMA）、ORB、MatterSim 和 SevenNet，并同时支持半经验（xTB）与经典（UFF）计算器。该平台支持全面的原子尺度模拟任务，包括单点能量、力和应力评估；原子化能和内聚能计算；结合多种优化器的几何优化；振动模分析；状态方程拟合；以及自旋态判定。通过批处理与轨迹分析功能，MLIP Studio 支持对分子构型进行高效高通量筛选，并可将 MLIP 预测系统地与 DFT 参考数据进行基准比较，同时自动生成 parity 图和误差指标。上传自定义 MACE 模型的能力进一步扩展了该平台在模型开发与诊断中的用途。此外，内置的墙钟时间记录还支持在不同硬件与模型家族之间系统地比较模型性能。

我们展示了若干突显该平台价值的实际应用。结果表明，基于 MLIP 的几何预优化可将后续 DFT 计算加速 $2\times$ 到 $33\times$，在分子与周期体系中都为传统基于 UFF 的预弛豫提供了有吸引力的替代方案。自旋判定功能在若干含过渡金属分子上得到了验证，其预测结果与实验已知基态一致，因此它是为 DFT 程序提供初始猜测值的有用工具。对 1000 个水盒构型进行跨模型势能面比较显示出令人放心的定性一致性，包括对最低能与最高能构型的完全一致识别，这增强了对通用 MLIP 用于构型筛选的信心。全面的 CPU 与 GPU 性能基准为模型选择提供了实用指导，表明不同模型的推理速度可相差一个数量级以上，且 CPU 与 GPU 上的相对速度排名会发生变化。我们还展示了如何利用构型系综的批量评估来提取最低能结构，以及在与 DFT 数据基准比较时识别高误差帧，从而改进微调与训练过程中的数据筛选。最后，CrCl3 /sapphire 案例研究展示了 MLIP Studio 如何作为一个完整工作流平台，用于处理一个具有化学真实性的体系，覆盖了体相基底验证、分子自旋态判定、表面与界面能学以及 AIMD 轨迹基准测试。结果表明，模型表现依赖于具体性质：例如，PET-OMAT-v1 M 在相对能量误差方面最优，而 UMA OMAT s1p1 在 CrCl3 /sapphire AIMD 轨迹的力预测一致性方面最佳，这进一步强调了面向任务选择 MLIP 的重要性。

展望未来，作者设想了若干发展方向。首先，若集成分子动力学能力，包括 NVT、NPT 和 NVE 系综，将能直接在平台内研究有限温度性质、扩散与相变。其次，加入用于过渡态搜索和最小能量路径确定的 NEB 计算，将拓宽平台在反应机理研究与催化中的适用性。第三，纳米团簇结构预测的全局优化方法也是自然扩展方向。第四，随着新的 MLIP 架构与模型继续快速涌现，MLIP Studio 的模块化插件架构旨在以很小的开发成本无缝吸纳它们。第五，开发能够串联多个任务的自动化工作流，例如几何优化后接振动分析以确认驻点性质，或对多个模型同时进行状态方程计算以开展交叉验证，将进一步提升生产效率。最后，作者通过官方仓库积极鼓励社区贡献新的任务、后处理工具和模型集成 [45]。

通过降低部署、比较和基准测试基础型 MLIP 的门槛，MLIP Studio 旨在加速 AI 与机器学习方法在日常计算化学和材料科学工作流中的应用，并成为一个共享基础设施，用于对快速增长的原子尺度模拟基础模型生态进行可重复且透明的评估。
