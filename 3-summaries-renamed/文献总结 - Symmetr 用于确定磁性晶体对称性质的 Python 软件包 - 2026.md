## 文献总结

### 研究背景与问题

晶体通常破坏连续空间的旋转和平移不变性，但保留一组离散对称操作。根据 Neumann 原理，晶体的物理性质必须在这些对称操作下保持不变，因此电输运、磁响应、磁相互作用等物理量的张量形式会受到晶体和磁结构对称性的限制。

对于非磁性晶体，空间群、点群和 Laue 群数量有限，许多物理性质可以通过表格查询。但对于磁性材料，必须考虑时间反演对称性，分类数量大幅增加：磁空间群有 1651 个，磁点群有 122 个，磁 Laue 群有 32 个。若进一步考虑无自旋轨道耦合的非相对论极限，则需要使用自旋群描述，群数更多，使穷举制表不现实。

本文提出的 Symmetr 软件包面向实际凝聚态研究中更常见的问题：给定一个具体晶体结构和具体磁结构，直接确定相关对称操作，并由此对目标张量进行对称化，而不要求用户先获得完整对称群分类。

### 软件定位

Symmetr 是一个用于确定晶体物理性质张量对称受限形式的 Python 软件包。它主要面向磁性材料中的响应张量，但也支持平衡性质、磁相互作用、局域站点投影物理量，以及磁有序参数展开。

软件可通过命令行或 Python API 使用。相对 Bilbao Crystallographic Server 上的 MTENSOR、STENSOR 以及 TensorSymmetry 等工具，Symmetr 的关键差异是输入以晶体结构和磁结构为中心，而不是以已知对称群为中心。这样的输入方式允许固定与实际晶体结构一致的坐标系，也便于处理局域站点对称性和磁有序参数展开。

### 核心方法

Symmetr 的流程分为 3 步：

1. 确定给定晶体和磁结构的对称操作。
2. 确定目标张量在这些对称操作下的变换规律。
3. 求解满足所有对称约束的最一般张量形式。

对于包含自旋轨道耦合的相对论情形，程序内部使用 Findsym 确定磁空间群对称操作。对于无自旋轨道耦合的非相对论极限，作者实现了自定义算法，用非磁晶体对称操作作为起点，并寻找可与空间操作组合成磁结构对称性的自旋旋转。

张量对称化被表述为线性方程组。对某个对称操作 $R$，张量必须满足：

$$
\chi^R_{ijk\ldots}=\chi_{ijk\ldots}
$$

这可写成：

$$
Yx=0
$$

其中 $x$ 是所有独立张量变量组成的向量，$Y$ 是由对称约束构造的数值矩阵。程序使用奇异值分解确定零空间，再通过高斯消元将结果转换为更适合输出的独立变量形式。作者指出，直接用高斯消元求解约束方程在数值上可能不稳定，因此默认采用 SVD 加高斯消元的混合策略。

### 支持的物理问题

Symmetr 支持响应模式和磁 Hamiltonian 模式。

响应模式中，用户指定响应观测量和扰动场观测量。例如用 `symmetr res j E -f Fe.in` 可获得 bcc Fe 中电导张量的时间反演偶分量和奇分量，其中奇分量对应反常 Hall 效应。程序总是分别输出时间反演偶和时间反演奇部分。

站点投影功能可用于局域物理量，例如反铁磁 CuMnAs 中特定 Mn 子晶格上的电场诱导有效磁场或自旋极化。该功能通过只保留使所选原子不变的对称操作实现，也可用 `-p2` 比较两个站点之间的对称关系。

有序参数展开功能用于共线磁系统。程序可将响应张量展开为磁有序参数 $n$ 的幂级数，例如 Fe 中电导张量对磁化方向的一阶展开给出反常 Hall 效应的最低阶展开项。

磁 Hamiltonian 模式用于确定 Heisenberg 型磁相互作用张量的对称形式。该模式可描述各向同性交换、各向异性交换、Dzyaloshinskii-Moriya 相互作用、磁晶各向异性以及高阶磁相互作用等半经典磁相互作用。但由于程序不区分原子属于哪个晶胞，它对不同晶胞间相互作用的完整一般处理有限，主要适用于宏自旋近似。

### 代码实现与性能

代码用 Python 编写，使用 Findsym 确定晶体和磁结构对称性，使用 SymPy 表示符号张量。用于响应张量、展开响应张量和磁 Hamiltonian 模式的主要函数分别是 `funcs_main.sym_res_nonexp(inp)`、`funcs_main.sym_res_exp(inp)` 和 `funcs_main.sym_mham(inp)`。

张量由 `tensors.Tensor` 类和用于数值对称化的 `tensors.NumTensor` 类表示。对称操作存储于 `symmetry.Symmetry` 类。对称化由 `symmetrize.symmetr()` 执行，它接收张量、对称操作列表以及张量变换函数。

程序在简单情形下速度很快，但随张量阶数升高，计算复杂度快速增长。作者以 Fe 中电导张量有序参数展开为例说明，运行时间随展开阶数近似指数增长。对低于 6 阶的张量，程序通常可在几分钟内完成。`--generators` 标志可通过仅使用群生成元显著加速高阶张量计算。

### 示例结果

论文给出 3 个示例：

1. Si 中 Hall 效应：使用 `symmetr res j E.B -f Si.in` 得到非磁 Si 中时间反演偶的 Hall 响应张量，可重写为 $j=-x_{210}E\times B$。
2. CuMnAs 中反铁磁自旋轨道转矩：使用站点投影得到两个磁性子晶格上的有效场响应张量。时间反演偶有效场在两个子晶格上呈交错形式，可有效耦合反铁磁有序；时间反演奇有效场为均匀形式，不能有效耦合反铁磁有序。
3. Mn3Sn 中非共线反铁磁的自旋极化电流：使用 `--noso` 分析非相对论对称性，得到时间反演奇的自旋极化电流张量，说明低对称反铁磁中可出现自旋极化电流。

### 结论与展望

作者认为 Symmetr 可用于凝聚态物理中大量对称性问题，既可处理常规相对论情形，也可处理非相对论极限；既可处理响应张量，也可处理磁相互作用。程序重点面向磁性体系，但也适用于非磁性体系。

当前限制主要包括：有序参数展开仅对共线系统实现；大阶张量由于指数标度而效率较低。作者提出未来可扩展非共线系统的有序参数展开，并通过 Cython、并行矩阵操作或 ScaLapack 等方式提高高阶张量计算性能。

## 摘要翻译

凝聚态化合物通常形成晶体，晶体破坏空间的旋转和平移不变性，但仍在一组离散对称操作下保持不变。理解这种对称性破缺所允许的效应，以及晶体结构施加的约束，是凝聚态物理中的一个关键问题。在这里，我们提出一个 Python 软件包，用于确定描述晶体物理性质的张量在对称性限制下的形式，尤其关注磁性材料。主要重点是响应张量；然而，该程序也可以描述平衡性质和其他物理性质，例如磁相互作用。程序可以使用常规磁空间群来描述对称性，也可以使用描述非相对论极限的自旋群来描述对称性。附加功能包括对投影到特定站点的物理量的处理，以及对磁有序参数的展开。代码既可以从命令行使用，也可以通过 Python API 使用。

## 引言翻译

对称性是凝聚态物理中的一个关键概念。晶体破坏空间的均匀性和各向同性，并且在某些情况下还破坏空间反演或时间反演对称性。这种对称性破缺导致多种多样的现象。例如，反演对称性破缺会导致自旋轨道转矩 [1]，即由电流诱导、作用在磁有序上的转矩。磁性材料中时间反演对称性的破缺会导致反常 Hall 效应 [2, 3]。然而，晶体通常仍在一组离散对称操作下保持不变，这限制了它们的响应性质。例如，虽然所有铁磁体都表现出反常 Hall 效应，但只有某些反铁磁体表现出该效应 [3]，这取决于晶体的对称性。

晶体的对称性质可以根据 Neumann 原理确定，该原理指出，如果晶体在某些对称元素下保持不变，那么它的任何物理性质也必须在相同对称元素下保持不变。这个原理约束晶体平衡性质和响应性质的形式。这些性质通常由张量表示，而确定此类张量在对称性限制下的形式是凝聚态物理中的一个重要课题。虽然在简单情形下可以手动完成，但对于更复杂的问题，这会变得不切实际或不可能，因此需要软件工具。

许多常见情形已经被制成表格。所有非磁性晶体的对称群都属于 230 个晶体学空间群。然而，对于描述晶体整体性质的物理现象，平移对称性无关紧要。在这些情况下，只需考虑 32 个晶体学点群。此外，对于在空间反演下不变的物理现象，只需考虑 11 个 Laue 群。这显著简化了对称性分类，并使许多现象的制表成为可能。

本工作的重点主要是磁性材料，对这些材料而言情况更复杂。磁性材料中的对称性分类需要包含时间反演对称性，这增加了对称群的数量。磁空间群有 1651 个，磁点群有 122 个，磁 Laue 群有 32 个。虽然为磁性材料中物理现象的对称性制表仍然可能，并且已经对许多性质完成 [4, 5, 6]，但它变得不太实用。

磁空间群隐含地假设存在自旋轨道耦合，这是一种将自旋自由度与晶格耦合起来的相对论相互作用。尽管所有材料中都存在自旋轨道耦合，但它通常很弱，可以作为微扰处理，甚至可以忽略。因此，考虑不存在自旋轨道耦合时的对称性，即非相对论极限，是有用的。在这种情况下，对称性由所谓的自旋群 [7, 8] 描述。最近，已经发表了自旋空间群的分类 [9]；然而，此类群的数量非常大，使得对称性受限物理性质的穷举制表不切实际。

在凝聚态研究中，人们通常感兴趣的是为具有特定磁结构的给定晶体确定某个具体物理性质的对称性。这正是 Symmetr 软件包所处理的问题。不需要完整分类；相反，只需确定相关对称操作，并相应地对给定张量进行对称化。这种方法还能够处理依赖站点群对称性或磁有序参数展开的局域现象，而仅知道空间群不足以处理这些问题。例如，描述反铁磁体系中的自旋轨道转矩时就需要这样做。这种方法还有其他优点；例如，从给定晶体结构出发，可以使坐标系相对于晶体得到一致固定。

还存在其他用于确定晶体对称性质的工具，特别是 Bilbao Crystallographic Server 上分别用于磁群和自旋群的 MTENSOR [6] 和 STENSOR [10] 工具，以及可同时处理二者的 TensorSymmetry [11]。这些程序提供与 Symmetr 类似的功能；然而，关键概念差异在于，Symmetr 的输入是晶体和磁结构，而这些工具为给定对称群确定对称性。从晶体结构出发具有若干优点，如上文所讨论，并且可能对用户更方便。这也意味着 Symmetr 是自包含的，不需要额外工具来确定对称群，例如用于确定磁空间群的 Findsym（随代码包含），或可用于确定自旋群的 FindSpinGroup 工具。相反，Symmetr 实现了自己的算法，用于为给定晶体确定自旋群对称性，从而不需要使用这些工具。在对称化方面，STENSOR 和 TensorSymmetry 都依赖 Mathematica，而 Symmetr 基于 Python，并且可通过 Python API 或命令行访问。STENSOR 中的对称化过程与 Symmetr 中的过程类似，只是直接应用高斯消元。相反，TensorSymmetry 使用 Mathematica 的符号功能求解约束方程。

## 方法翻译

原文没有名为 “Methods” 的章节；此处翻译论文第 2 节 “Methodology”。

为了确定描述给定晶体中某种物理现象的张量在对称性限制下的形式，需要 3 个步骤：

1. 确定对称操作。
2. 确定张量在对称操作下的变换。
3. 找到满足对称操作所施加限制的最一般张量形状。

在包含自旋轨道耦合的情形下，即磁空间群情形，Symmetr 软件包内部使用 Findsym 程序 [12, 13] 来确定对称操作。Findsym 是一个成熟工具，用于为给定晶体结构和磁有序确定磁空间群。Findsym 程序的输入也作为 Symmetr 的输入，并在第 3.1 节以及文档中详细描述。在非相对论情形下，程序实现了一个自定义算法，用于确定所有对称操作。该算法在第 2.8 节中详细描述。

为了确定给定张量如何在对称操作下变换，需要考虑它的构成关系。在磁空间群中，需要考虑 4 种不同类型的对称操作：旋转、空间反演、时间反演和平移。当使用自旋群时，还必须额外考虑纯自旋旋转。

### 旋转下的变换

我们以电导张量 σ 为例，它定义为：

$$
j=\sigma E,
$$

其中 $j$ 是电流，$E$ 是施加的电场。因为物理定律在旋转下不变，所以对于旋转 $R$，必须有：

$$
Rj=\sigma^R RE,
$$

其中 $\sigma^R$ 是旋转后体系的电导张量。这个方程可以直观地理解为旋转整个实验，而这不能改变结果。将该方程乘以 $R^{-1}$ 并显式写出指标，得到：

$$
j_i=R^{-1}_{ik}R^T_{jl}\sigma^R_{kl}E_j.
$$

这个方程必须对所有 $j$ 和 $E$ 成立。与上式 $j=\sigma E$ 比较可得：

$$
\sigma_{ij}=R^{-1}_{ik}R^T_{jl}\sigma^R_{kl}
\Leftrightarrow
\sigma^R_{ij}=R_{ik}R^{-T}_{jl}\sigma_{kl}.
$$

这里 $R^{-T}$ 表示矩阵 $R$ 的逆矩阵再转置。因此这给出了电导张量的变换。可以看到，张量的两个指标以不同方式变换。这被称为张量的协变指标和逆变指标：指标 $j$ 是逆变的，指标 $i$ 是协变的。二者的差异来自它们在坐标系改变下的变换方式。然而，协变指标和逆变指标的差异只在非笛卡尔坐标系中重要。在笛卡尔（正交归一）坐标系中，它们以相同方式变换。这可以从在笛卡尔坐标系中 $R^{-T}=R$ 看出。

对应于晶体整体性质的一般张量将以相同方式变换：

$$
\chi^R_{i\ldots j,k\ldots l}
=R_{im}\ldots R_{jn}R^{-T}_{ko}R^{-T}_{lp}\chi_{m\ldots n,o\ldots p},
$$

其中指标 $i\ldots j$ 是逆变的，指标 $k\ldots l$ 是协变的。

### 反演下的变换

同样的方法也可以应用于空间反演。因为反演由矩阵

$$
P=
\begin{pmatrix}
-1&0&0\\
0&-1&0\\
0&0&-1
\end{pmatrix}
$$

表示，所以协变指标和逆变指标之间没有差异。然而，指标会根据它们对应的是极性矢量还是轴性矢量而以不同方式变换：极性矢量在反演下改变符号，而轴性矢量不改变符号。以电导张量为例，因为 $j$ 和 $E$ 都是极性矢量，所以该张量的两个指标在反演下都改变符号，这意味着张量整体在反演下不变。

### 平移和原子置换下的变换

对于对应于整体物理现象的张量，平移不起作用。然而，当我们关注局域性质，例如特定磁性站点上的转矩时，平移也必须考虑。重要信息是某个特定对称操作如何变换各个原子，作者将其称为原子置换。考虑一个把原子 $a$ 变换为原子 $b$ 的对称操作 $R$，对于站点投影响应张量 $\chi^a$ 有：

$$
\chi^R_b=\chi_a,
$$

其中 $\chi^R$ 表示张量被对称操作变换后的形式。由于平移不直接起作用，代码内部不存储平移；只存储原子位置的置换。

### 时间反演对称性

时间反演是一种在微观运动方程中反转时间方向的对称性。因此，它也反转轨道角动量和自旋角动量。这就是为什么它被用作磁有序晶体分类中的附加对称性。时间反演对称性的张量变换不能像晶体学对称操作那样由构成关系推导。Birs [14] 已经注意到这个问题。以电导张量为例，电场在时间反演下是偶的，而电流是奇的。由于非磁性晶体在时间反演对称性下不变，我们会发现对称性不允许非磁性晶体中存在电导，这显然是错误的。Shtrikman 和 Tomas [15] 以及后来 Grimmer [16] 讨论过这种朴素方法的问题。问题的核心在于，电流是耗散过程，对其微观运动路径进行反转没有物理意义。

Onsager 研究了耗散过程理论，并推导出所谓的 Onsager 关系 [17]。对于电导，这些关系为：

$$
\sigma_{ij}([M],H)=\sigma_{ji}(-[M],-H),
$$

其中 $[M]$ 表示磁构型，即磁矩或磁化密度，$H$ 表示外磁场。因此这意味着电导张量的对称分量是时间反演偶的，而反对称分量是时间反演奇的。这给出了如何通过时间反演对称性变换张量的规则：首先将张量分解为对称分量和反对称分量，然后分别对每个分量进行时间反演变换。

电导是一个特殊情形，因为 Onsager 关系将张量与其自身联系起来。在一般情况下，Onsager 关系将某个效应与其逆效应联系起来。例如，由温度梯度诱导的电流和由电压产生的热流。在这种情况下，Onsager 关系本身并不限制响应张量的形式。然而，仍然可以将任意张量分解为时间反演偶分量和时间反演奇分量：

$$
\chi_e([M])=\frac{\chi([M])+\chi(-[M])}{2},
$$

$$
\chi_o([M])=\frac{\chi([M])-\chi(-[M])}{2}.
$$

这在实践中很有用，因为这两个分量通常表现不同，并且常常在理论和实验中分开处理。例如，对于自旋轨道转矩，时间反演奇分量对应场型转矩，而时间反演偶分量是反阻尼型转矩。时间反演下的变换也可以从微观公式推导。量子力学中的时间反演算符为：

$$
\hat{T}=iK\sigma_y,
$$

其中 $K$ 表示复共轭，$\sigma_y$ 是 $y$ Pauli 矩阵。通过直接变换线性响应的 Kubo 公式，可以看到它包含两个具有相反变换性质的分量，因为一个分量含有矩阵元的实部，而另一个含有虚部。这种方法已经在若干工作中使用 [4, 5, 18]。

### 自旋旋转

在磁空间群中，所有实空间旋转都与相应的自旋空间旋转耦合。由于镜面对应于旋转和反演的组合，而自旋在反演下不变，因此镜面与镜面旋转部分对应的自旋旋转耦合。对应于自旋的指标将由自旋旋转矩阵变换。在自旋群情形中，实空间部分和自旋空间部分解耦，因此实空间变换可以与任意自旋旋转组合。

### 磁相互作用

磁相互作用通常用 Heisenberg 型 Hamiltonian 描述，其形式为：

$$
H=\sum_{ab,ij}H^{(2)}_{ab,ij}M_i^aM_j^b
+\sum_{abcd,ijkl}H^{(4)}_{abcd,ijkl}M_i^aM_j^bM_k^aM_l^a+\ldots,
$$

其中 $M_i^a$ 是站点 $a$ 上磁矩的第 $i$ 个分量。$H^{(n)}_{ab\ldots,ij\ldots}$ 张量是对应于各种磁相互作用的展开系数，其对称性需要确定。任何半经典磁相互作用都可以用这样的 Hamiltonian 描述，包括各向同性和各向异性交换、Dzyaloshinskii-Moriya 相互作用、磁晶各向异性或高阶相互作用。这些张量的对称化遵循与响应张量相同的原理；然而，由于它有一些特殊之处，作者在这里单独讨论。

为了确定 $H^{(n)}_{ab\ldots,ij\ldots}$ 张量的对称性，必须考虑非磁性晶体的对称操作。这是因为这些对称操作会把磁性晶体的不同磁构型联系起来。考虑一个对称操作 $\hat{R}$，它使磁矩按如下方式变换：站点 $a$ 上的磁矩由 $R_{ij}M_j^{p^{-1}(a)}$ 给出，其中 $R_{ij}$ 是表示磁矩在 $\hat{R}$ 下变换的矩阵，也就是时间反演奇轴性矢量的变换矩阵，$p$ 是 $R$ 下原子的置换。这意味着在 $R$ 下，原子 $a$ 变换到原子 $p(a)$，原子 $p^{-1}(a)$ 变换到原子 $a$。由非磁晶格某个对称性联系起来的所有磁构型必须具有相同能量。为简单起见，考虑二阶项，必须有：

$$
\sum_{ab,ij}H^{(2)}_{ab,ij}M_i^aM_j^b
=
\sum_{ab,ij}H^{(2)}_{ab,ij}R_{ik}M_k^{p^{-1}(a)}R_{jl}M_l^{p^{-1}(b)}.
$$

由于 $a$ 和 $b$ 与 $p(a)$ 和 $p(b)$ 都遍历所有原子站点，可以将求和变量替换为 $p(a)$ 和 $p(b)$。于是得到：

$$
\sum_{ab,ij}H^{(2)}_{ab,ij}M_i^aM_j^b
=
\sum_{ab,ij}R^T_{ik}R^T_{jl}H^{(2)}_{p(a)p(b),kl}M_i^aM_j^b,
$$

其中也转置了 $R$ 矩阵并交换了求和指标 $i\leftrightarrow k$ 和 $j\leftrightarrow l$。因为这必须对所有 $M^a$ 成立，得到：

$$
H^{(2)}_{ab,ij}=R^T_{ik}R^T_{jl}H^{(2)}_{p(a)p(b),kl}.
$$

因此这给出了张量 $H^{(2)}$ 的变换规则。更高阶情形可完全类似地推导。此外，还必须施加一个约束：对于对应于同一原子的指标互换，张量必须是对称的。

对 $H^{(n)}_{ab\ldots,ij\ldots}$ 张量进行对称化时，必须跟踪原子置换。这里代码适用性有一个重要限制。在代码中，作者不跟踪原子属于哪个晶胞。也就是说，代码不区分将原子 $a$ 变换到同一晶胞中原子 $b$ 的变换，和将原子 $a$ 变换到不同晶胞中原子 $b$ 的变换。这意味着代码不能区分例如 $H^{(2)}_{ab,ij}$ 中 $a$ 和 $b$ 位于同一晶胞时的对称性，以及 $a$ 和 $b$ 位于不同晶胞时的对称性。因此，代码只能在所谓宏自旋近似中描述磁相互作用；在该近似中，样品仅由单个畴组成，不同晶胞中的同种原子都具有相同磁矩方向，因而可视为等价。可以将位于相同位置的两个原子指定为非等价，这会关闭这些指标的对称化。这在大多数情况下足以处理不同晶胞中原子之间的相互作用；然而，不同晶胞中相互作用的完整一般处理尚不支持。

### 磁化中的展开

对于磁性体系，响应张量可以按磁有序参数展开。在代码中，该功能只对共线体系实现，共线体系由单个有序参数 $n$ 描述：

$$
\chi_{ijk}(n)=\chi^{(0)}_{ijk}+\chi^{(1)}_{ijkl}n_l+\chi^{(2)}_{ijklm}n_ln_m+\ldots
$$

展开张量的变换可以用类似磁相互作用的方式确定。与磁相互作用情形类似，必须考虑非磁性对称操作。在单子晶格铁磁体中，有序参数是净磁化，它作为时间反演奇轴性矢量变换。在具有多个磁性子晶格的体系中，情况可能更复杂，有序参数的变换必须基于原子的置换来确定。

### 非相对论对称性

在没有自旋轨道耦合时，对称性由所谓的自旋群 [7, 8] 描述。它们不同于描述相对论对称性的磁空间群，因为自旋旋转和空间旋转解耦。也就是说，在有自旋轨道耦合时，一个旋转由实空间旋转和等价的自旋旋转组成。然而，在没有自旋轨道耦合时，自旋旋转可以不同于实空间部分。

在非磁性体系中，自旋群是晶体学空间群、包含所有自旋旋转的群和时间反演的乘积。在磁性体系中，对称性降低。例如，磁性体系在时间反演或任意自旋旋转下不再不变。

由于磁性体系的所有对称操作也必须是非磁性体系的对称操作，作者使用非磁性体系的对称操作作为起点。作者假设体系的对称性通过为每个站点指定磁矩来描述。这通常满足；然而，也可能需要考虑整个磁化密度。在这种情况下，根据这里所用方法确定的对称性会高于真实体系中的对称性。不过，这里概述的一般原理仍然适用。

获得非相对论对称操作的过程如下：

1. 识别所有非磁性对称操作。为此，作者使用 Findsym 代码。只考虑对称操作的空间部分，并且需要寻找任意自旋旋转，使其与空间部分一起成为磁性体系的对称性。
2. 因为空间变换和自旋变换解耦，所以空间对称操作中对自旋旋转唯一重要的方面是它们如何置换磁性原子。也就是说，在组合自旋旋转 $R_s$ 和空间变换 $R$ 下，体系的磁矩会变换为 $M_a\rightarrow R_sM_{p(a)}$，其中 $p(a)$ 表示对应于 $R$ 的置换。如果对所有磁矩都有 $M_a\rightarrow R_sM_{p(a)}$，则组合操作是体系的对称性。例如，一个对称操作可能将原子 A 变换到原子 B，原子 B 变换到原子 C，原子 C 变换到原子 A。作者将这个操作记为 A → B → C → A，并称其为置换链。每个置换链必须以与起始原子相同的原子结束。每个对称操作由一个或多个这样的链描述。
3. 现在，对于每个置换链，必须找到使它保持不变的自旋旋转，即满足 $R_sM_{c_i}=M_{c_{i+1}}$ 的自旋旋转，其中 $M_{c_i}$ 表示链中每个原子的磁矩。这必须分别在有时间反演和无时间反演两种情况下完成。以下假设所有磁矩具有相同大小，否则它们不可能由对称性联系起来。

由于链的最后一个元素必须与第一个元素相同，存在条件：

$$
\text{无时间反演：}\quad M_A=R_s^nM_A
$$

$$
\text{有时间反演：}\quad M_A=(-1)^nR_s^nM_A
$$

其中 $n$ 是链中唯一原子的数目，即对于链 A → B → C → A，长度为 3。由此可以确定使链保持不变的自旋旋转存在所需的条件。

如果该链是共线的，则对称性分析相当简单。唯一两个相关对称性是绕共线轴的任意旋转 $R_s^{||}$，以及绕任意垂直轴的 π 旋转 $R_s^{\perp}$。体系可以在 $R_s^{||}$ 下不变，也可以在 $R_s^{\perp}R_s^{||}$ 下不变。在这种情况下，链具有连续自旋旋转对称性。

对于非共线体系，旋转角 θ 的条件为：

- 无时间反演，或有时间反演且 $n$ 为偶数：$\theta=i\pi/n$，其中 $i$ 是偶整数。
- 有时间反演且 $n$ 为奇数：$\theta=i\pi/n$，其中 $i$ 是奇整数。

4. 对链中的每个置换对，接下来必须确定使其保持不变的自旋旋转，同时考虑对 θ 的限制。作者首先分别考虑每一对。例如，对于链 A → B → C → A，必须找到满足 $R_sA=B$、$R_sB=C$ 和 $R_sC=A$ 的自旋旋转 $R_s$，然后找到所有对共有的自旋旋转。

一般而言，可以证明，如果存在一个角度为 θ、连接两个矢量 $M_A$ 和 $M_B$ 的旋转 $R_s$，则需满足 $M_A\cdot M_B\geq \cos(\theta)$，也就是说两个矢量之间的角度必须大于或等于 θ。旋转轴由下式给出：

$$
n_1^+=\cos(\alpha)\frac{M_A+M_B}{||M_A+M_B||}
+\sin(\alpha)\frac{M_A\times M_B}{||M_A\times M_B||},
$$

$$
n_1^-=-\cos(\alpha)\frac{M_A+M_B}{||M_A+M_B||}
-\sin(\alpha)\frac{M_A\times M_B}{||M_A\times M_B||},
$$

$$
n_2^+=\cos(\alpha)\frac{M_A+M_B}{||M_A+M_B||}
-\sin(\alpha)\frac{M_A\times M_B}{||M_A\times M_B||},
$$

$$
n_2^-=-\cos(\alpha)\frac{M_A+M_B}{||M_A+M_B||}
+\sin(\alpha)\frac{M_A\times M_B}{||M_A\times M_B||},
$$

其中：

$$
\alpha=\arccos\left(
\sqrt{\frac{2(M_A\cdot M_B-\cos(\theta))}
{(1-\cos(\theta))(1+M_A\cdot M_B)}}
\right).
$$

± 轴对应相反的旋转方向。一般来说，二者中只有一个是正确的。对于给定的 $M_A$、$M_B$ 和 θ，可以很容易检查哪一个是正确的。

5. 一旦得到作为每个置换链对称性的自旋旋转，就寻找所有链共有的自旋旋转，如果存在的话。这些自旋旋转与对应于该置换的空间部分以及可能的时间反演一起，就是体系的对称性。

### 张量对称化

一旦得到给定体系的对称性以及张量在这些对称性下的变换，就可以通过求解一组由对称性施加的线性方程，确定给定张量的一般对称受限形状。作者以迭代方式进行对称化：每次考虑一个对称性，并将一个对称性的对称化输出作为下一个对称性的对称化输入。对于给定对称性 $R$，必须有：

$$
\chi^R_{ijk\ldots}=\chi_{ijk\ldots}
$$

作者使用变量 $x_{ijk\ldots}$ 表示张量的独立分量。在对称化过程开始时，$\chi_{ijk\ldots}=x_{ijk\ldots}$。一般而言，$\chi$ 和 $\chi^R$ 的分量都是 $x_{ijk\ldots}$ 的线性组合。因此，上式可以改写为：

$$
Yx=0,
$$

其中 $x$ 是由所有 $x_{ijk\ldots}$ 变量组成的向量，$Y$ 是一个数值矩阵，其维度为 $3^n\times 3^n$，其中 $n$ 是张量 $\chi$ 的阶数。这是一个线性方程组，一般要么只有零解，要么有无限多个解。在前一种情况下，$x_{ijk\ldots}=0$，因此张量为零。在后一种情况下，如果解空间，即零空间，的维度小于初始变量总数，则体系受到约束，并且可以消去一些变量。这可以方便地通过高斯消元将矩阵变换为简化行阶梯形来实现；然而，在实践中，这种方法在数值上不稳定，并且在少数情况下会导致错误结果 [19]。

为解决这一问题，作者使用 SVD 分解确定 $Y$ 的零空间基。向量 $x$ 因此是零空间基矢 $a_i$ 的线性组合：$x=\sum_{i=1}^k\alpha_i a_i$，其中 $k$ 是零空间维度，$\alpha_i$ 是可取任意值的系数。现在可以把 $\alpha_i$ 用作新的独立变量；然而，在实践中，作者希望保留某些原始变量并消去其他变量。为了方便实现这一点，作者使用这些基矢构造新矩阵 $\tilde{Y}$：

$$
\tilde{Y}=
\begin{pmatrix}
a_1^T\\
a_2^T\\
\vdots
\end{pmatrix}.
$$

这里使用转置是为了表示 $a_1^T$ 是行向量。随后使用高斯消元将 $\tilde{Y}$ 变换为简化行阶梯形 $\tilde{Y}_{rref}$，并将 $\tilde{Y}_{rref}$ 的行记为 $a_i^{\prime T}$。当向量 $x$ 用这些新的行约化基矢展开为 $x=\sum_{i=1}^k\alpha_i a_i^\prime$ 时，对应于主元列的变量 $x_i$ 与自由参数 $\alpha_i$ 精确地一一对应。因此，与主元列相关的变量成为独立变量，而非主元列给出依赖变量的线性组合。该过程在附录 A 的简单例子中说明。

原则上，即使在这种情况下，高斯消元也可能失败。然而，因为 $a_i$ 矢量正交且归一，带部分主元选取的标准高斯消元在实践中效果很好。此外，任何潜在问题都很容易检测，因为可以轻易检查 $a_i^\prime$ 中没有零矢量，并且所有 $a_i^\prime$ 都满足 $Ya_i^\prime=0$。代码会自动完成这一检查。

## 结论翻译

原文没有名为 “Conclusion” 的单数章节；此处翻译第 6 节 “Conclusions and outlook”。

Symmetr 可用于解决凝聚态物理中大量问题的对称性。它可以描述大多数响应张量以及磁相互作用，既可用于常规情形，也可用于非相对论极限。主要重点是磁性体系；然而，非磁性体系也可以考虑。除当前已实现的张量之外，其他类型的张量也可以很容易添加；只需指定该张量的变换规则。Python API 允许将程序集成到各种 Python 工作流中。该程序相对成熟；然而，未来还可以实现其他功能。目前，展开只对共线体系实现。为非共线体系实现这一功能会很有用；然而，这将需要显著改变该功能的实现方式，因为非共线体系具有不止一个磁参数。对于大张量，代码由于指数标度而变得低效。这可以通过例如对数值密集部分使用 Cython 来改进，也可能通过使用 ScaLapack 或类似库对矩阵操作部分，例如 SVD 分解，进行并行化来改进。
