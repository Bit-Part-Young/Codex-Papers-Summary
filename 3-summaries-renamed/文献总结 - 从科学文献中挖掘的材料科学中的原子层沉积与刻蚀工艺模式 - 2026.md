## 论文内容详细总结

- **研究问题与动机**
    - 原子层沉积（ALD）与原子层刻蚀（ALE）分别通过自限性循环反应实现表面材料的受控添加与去除，是半导体制造和纳米材料工程的重要工艺。
    - 文献中对同类 ALD/ALE 过程的报告高度异构：术语和单位不一致，信息散落在正文、图表和补充材料中；实验研究强调前驱体、剂量、吹扫、设备和实测性质，模拟研究则强调计算方法、表面模型、反应路径和预测量。
    - 这种异构性阻碍跨论文比较、实验—模拟整合，以及数据库、知识图谱、信息抽取和机器学习中的可复用性。现有 AtomicLimits 数据库证明了结构化访问的价值，但尚缺同时覆盖 ALD/ALE、实验/模拟、可独立验证且带有量纲—单位语义约束的开放规范。

- **核心产出与方法**
    - 作者构建四个相互协调、经领域专家审阅的 JSON Schema：ALD 实验、ALD 模拟、ALE 实验和 ALE 模拟；每个实例对应一条“论文所报告的单一工艺”，而非整篇论文，因此一篇论文可产生多条记录。
    - 结构设计采用 schema-miner 的三阶段、人机协作流程：领域过程规范生成初始模式；以代表性论文和专家反馈迭代修订；再以更大文献语料验证覆盖度直至专家认可。
    - 经过 schema-miner_pro 处理后，所有物理量属性接地到 QUDT：数值、单位、quantity kind 分离编码，并通过限定的 QUDT IRI 实现单位感知验证和跨论文归一化比较。
    - 四个模式也被转换为 ORKG 模板；作者以 ALD 实验模式示范从文献抽取结构化记录并发布到知识图谱的应用。

- **四个模式的结构与关键差异**
    - **ALD 实验模式**：6 个顶层组、最大嵌套深度 8、275 个总属性（去除 QUDT 辅助字段后 95 个）、30 个必填属性。它最细致地覆盖从沉积化学、反应物、反应器条件、超循环，到薄膜光学/电学/成分/形貌性质与器件性能的全过程。
    - 该模式的特色是“化合物—角色”成对的数组表达，可表征多组分沉积；膜成分以元素—浓度对记录；supercycleDesign 描述构建三元、四元、纳米层压或掺杂薄膜的子循环顺序和比例；四种模式中只有它包含器件性质，且以薄膜晶体管为目标应用。
    - **ALD 模拟模式**：8 个顶层组、最大深度 6、212 个总属性（去除 QUDT 后 68 个），仅 3 个必填属性。它要求至少明确计算方法和材料体系，并重点表达吸附、表面羟基浓度、形核延迟、选择性生长等模拟更容易直接给出的表面与机理信息。
    - **ALE 实验模式**：11 个顶层条目、最大深度 7、167 个总属性（去除 QUDT 后 47 个）、20 个必填属性。它明确区分被刻蚀材料、工艺类型和各向异性/各向同性，并组织两步反应物、脉冲/吹扫、刻蚀每循环、协同效应、ALE 窗口、选择性及安全/可持续性等信息。
    - **ALE 模拟模式**：8 个顶层组、最大深度 7、275 个总属性（去除 QUDT 后 83 个）、56 个必填属性，是四者中规范性最强者。它涵盖基底与原子级表面模型、模拟条件、刻蚀物和副产物、表面改性、分解与自限机理、速率及计算方法；32 个 QUDT 接地属性为四者最多，其中 29 个带物理合理数值范围约束。

- **跨模式共同基础**
    - 四种模式都表达反应化学、受处理材料或基底、过程条件和得到的材料性质，但在路径及粒度上不同。
    - QUDT 量纲的共同核心有 6 个：能量、长度、压力、温度、厚度和时间。作者将语义相近量统一映射，例如将压力统一为 StaticPressure、每循环生长映射为 Thickness，从而提高共同核心的一致性。
    - 去除 QUDT 辅助字段并人工归一化不同命名后，四个模式共同的领域属性为：薄膜化学组成、压力、主要前驱体/反应物、反应物流量和基底材料。两个模拟模式还更共同地覆盖计算方法、表面化学、反应器条件与预测薄膜行为。

- **验证价值与应用结果**
    - 在 ZnO 和 IGZO 的 ALD 文献抽取示例中，模式作为“抽取蓝图”，规定需要抽取的信息以及输出结构；输出记录接受模式符合性检查，化学实体归一化为 PubChem 标识符。
    - 类型、必填结构、quantity kind、允许单位及数值范围的验证能阻止负持续时间、负流量等结构上或物理上不合理的值被静默接纳；一个 115 Å 的“每循环生长”值也被追溯并标记为不正确的膜厚增量。
    - 语料应用同时揭示了报告覆盖率：沉积材料、前驱体、共反应物和工艺气体等化学信息较常完整，生长每循环、剂量持续时间和吹扫持续时间等定量信息则更不均匀。

- **结论与限制/展望**
    - 该工作提供了可机器验证、可在 ORKG 发布、可驱动文献抽取的 ALD/ALE 工艺级资源，并在保持工艺与视角特异性的同时建立共享语义基础。
    - 当前本体接地仅覆盖定量属性。后续将以 PMDco 等材料科学本体扩展到材料、加工方法、结构、性质、表征或模拟活动等非定量概念，并结合更广文献与专家评估以提升跨模式对齐和 AI 可用性。

## 章节翻译

### 摘要

材料科学中的实验和模拟文献对原子层沉积（ALD）与原子层刻蚀（ALE）的报道并不一致，这妨碍了比较以及机器可操作的复用。我们提出了四个经过领域专家审阅的 JSON Schema，分别用于 ALD 和 ALE 的实验与模拟工艺。这些模式使用 schema-miner 进行整理，并利用 schema-miner_pro 以 QUDT 为基础进行语义接地；它们对材料、工艺条件、配置以及测得或预测的结果进行结构化。我们比较其范围、结构和语义接地，并展示它们在模式引导的文献抽取以及通过 ORKG 模板发布结构化记录中的使用。

### 引言

原子层沉积（ALD）[1] 和原子层刻蚀（ALE）[2] 是用于受控添加和去除表面材料的互补循环过程。ALD 通过顺序进行的自限性反应沉积薄膜，而 ALE 通过自限性反应步骤去除材料。它们对薄膜厚度、组成、保形性和材料去除的精确控制，使原子层加工对于半导体制造和纳米尺度材料工程十分重要。关于这些过程的知识分布在报告不同类型信息的实验和计算研究之中。实验研究描述反应物、工艺条件、剂量和吹扫时间、生长或刻蚀速率、表征方法以及测得的性质，而模拟聚焦于计算方法、表面模型、反应路径和预测量。这些视角针对相同的过程，但在内容和组织上显著不同。

随着化学与材料研究采用自动化实验、数据驱动分析和计算决策，连接这些视角变得愈加重要。自动化薄膜制备已经得到展示 [3]，而机器可读的化学程序能够将已发表的方案连接到可执行的实验室工作流 [4, 5]。标准化数据格式和模块化测量系统还表明，实验输入、条件和输出的可互操作描述对于整合仪器、软件和科学数据至关重要 [6]。然而，ALD 和 ALE 过程的报道并不一致：等价概念使用不同术语或单位，信息分散在文本、表格、图和补充材料中，且所报告的参数和结果差异很大。这些不一致性妨碍了跨出版物比较、实验和模拟结果的整合，以及在数据库、知识图谱、信息抽取系统和机器学习工作流中的复用。尽管 AtomicLimits 的 ALD 和 ALE 数据库展示了结构化访问的价值 [7, 8]，用于实验和模拟过程的、开放可复用且可机器验证的规范仍然不可用。

在本工作中，我们提出四个协调的工艺模式：ALD 实验、ALD 模拟、ALE 实验和 ALE 模拟。每个模式实例代表文献所报道的单一过程，而不是整篇出版物，因此每项研究可有多条记录。这些模式在嵌套的、以过程为导向的结构中组织材料、实验或计算条件、工艺细节以及测得或预测的结果。由于沉积和刻蚀涉及不同的材料转变，而实验和模拟具有不同的信息需求，因此需要分别的模式。这些模式使用 schema-miner [9] 整理；该人机协作工作流结合大语言模型、代表性出版物和迭代式领域专家审阅。随后使用 schema-miner_pro [10] 对其处理，使定量属性接地到 Quantities, Units, Dimensions and Data Types（QUDT）本体 [11]。所得 JSON Schema 区分必需与可选信息、约束数据类型和受控取值，并将定量属性链接到明确的 quantity kind 和允许单位。相应的 ORKG 模板支持结构化学术知识的发布 [12]。

主要贡献如下：

- 四个开放可用、经领域专家审阅的 JSON Schema，涵盖 ALD 和 ALE 的实验及模拟过程 [13]；
- 对其范围、结构、必需信息、领域属性覆盖和 QUDT 接地的系统比较；以及
- 对模式引导的 ALD 过程信息抽取和通过 ORKG 模板发布结构化过程记录的展示。

在我们此前介绍并实证评估模式发现和本体接地操作工作流的 schema-miner [9] 与 schema-miner_pro [10] 论文基础上，本文聚焦所得的 ALD 和 ALE 资源及其面向应用的建模决策。我们考察这些工作流如何被应用、模式捕获了什么、四种表示如何相互关联，以及它们如何实现工艺知识的机器可操作复用。

### 方法

本文的“ALD/E Experimental/Simulation Schema Curation Methodology”章节承担方法部分的功能，以下为其完整翻译。

四个模式均使用 schema-miner [9] 整理；该方法分别独立应用于实验 ALD、模拟 ALD、实验 ALE 和模拟 ALE 研究。实验和模拟研究报告的信息在结构上不同：实验论文描述测得的工艺条件（例如前驱体剂量和吹扫时间、基底温度）及表征材料，而模拟论文描述计算方法参数（例如所用模拟方法以及 DFT 泛函等方法特异设置）和预测或建模的量。这一区别促使我们针对每种过程的实验和模拟视角分别整理模式，而非使用一个合并的表示。

schema-miner [9] 工作流由三个阶段组成。第一阶段中，从领域特异的过程规范文档生成初始模式，该文档描述该过程预期的主要实体、参数和输出。第二阶段使用相对较小的一组有代表性的科学出版物进行文献引导的细化。将这些出版物中报告的信息与初始模式比较，以识别缺失属性、规定不充分的概念、不恰当的数据类型和结构不一致性。随后，使用文献导出的证据以及领域专家提供的反馈修订模式。在第三个也是最后一个阶段，将细化后的模式应用于大得多的出版物语料库。该阶段通过让模式接触更广范围的材料体系、工艺配置和实验条件来拓宽其覆盖范围。迭代过程持续进行，直至领域专家认为所得模式对相应的 ALD 或 ALE 文献足够完整、正确并具有代表性。

本工作使用的出版物语料由 ALD 和 ALE 领域专家整理。主要选择准则是科学质量，同时确保覆盖 ALD 和 ALE 内多样化的材料、工艺条件、方法学场景和应用领域。目标是让 schema-miner 接触覆盖广泛相关报告实践的高质量研究。在细化阶段（阶段 2），ALD 实验和模拟模式各使用 7 篇出版物，ALE 实验模式使用 9 篇，ALE 模拟模式使用 10 篇。在定稿阶段（阶段 3），语料扩大至 ALD 实验 59 篇出版物、ALD 模拟 51 篇、ALE 实验 38 篇和 ALE 模拟 22 篇。

在结构整理之后，使用 schema-miner_pro [10] 对模式进行处理，以将表示物理量的属性在 QUDT 本体 [11] 中进行语义接地。该接地为物理量的含义及其允许单位提供共同的语义参照。它支持对文献中遇到的异构单位进行归一化，并促进跨出版物数值的机器辅助比较。每个已接地属性均包含一个数值、一个 QUDT quantity-kind IRI，以及一个或多个 QUDT unit IRI。在 JSON Schema 中，这些映射通过 quantityValue、quantityKind、hasQuantityKind 和 sameAs 字段表示。表 2 报告了每个最终模式中经 QUDT 接地的属性数量。

最终模式在 Zenodo [13] 上开放获取。除 JSON Schema 外，四个模式还全部被转换为 ORKG 模板，以支持 Open Research Knowledge Graph [12] 内的结构化学术知识表示。第 4 节详细描述了所得四个模式的结构，包括前述实验和模拟视角各自特有的设计决策。

### 结论

本工作提出了四个经 QUDT 接地的 JSON Schema，用于原子层沉积和原子层刻蚀的实验与模拟研究。这些模式利用 schema-miner 开发，在保留工艺和视角特异概念的同时，捕获了共同的工艺级基础。QUDT 接地通过数值、单位和 quantity kind 显式表示定量值，从而支持单位感知验证和跨出版物比较。它们在智能体式文献抽取工作流中的使用进一步表明了其实际价值：作为将科学论文转换为符合模式的结构化记录的目标。

当前的本体对齐聚焦于通过 QUDT 处理定量属性。未来工作将使用 Platform MaterialDigital Core Ontology（PMDco）[15] 等材料科学本体，把这种接地扩展到非定量概念，包括材料、加工方法、结构、性质以及表征或模拟活动。连同进一步的领域专家细化和在更广文献语料上的评估，这将加强跨模式对齐，并支持更具可互操作性、可复用性和 AI 就绪性的 ALD/ALE 知识。
