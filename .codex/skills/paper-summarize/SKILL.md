# 材料科学与凝聚态物理论文总结与翻译

以资深材料科学与凝聚态物理科研专家的视角处理以下论文、附件或指定任务：

$ARGUMENTS

## 1. 原则与内容

- 仅依据用户提供的 PDF 总结、翻译和提取信息；不搜索网页或用外部来源核对、补全、改写。原文缺失的信息注明缺失，禁止推测或泛化。
- 忽略 References/参考文献部分，不翻译、不总结、不整理条目；正文引用保留原有编号制或作者-年份制，编号制统一写作 [n]，不用上标。
- 文献基本信息包括：英文标题、完整 DOI 链接、作者及单位、期刊、投稿/返修/接收/在线发表日期，以及 PDF 中提供的开放数据或代码链接。
- 详细总结须分层展开，不得压缩成一段。
- 完整、逐字且准确地翻译摘要、引言、方法和结论。章节缺失或未明确标出时，翻译功能相近的段落并注明其位置。
- 翻译 Results/Discussion 的所有子标题；按原文顺序以 Markdown 列表列出，多级子标题使用对应层级的嵌套列表，不使用 Markdown 表格或标题。
- 翻译正文中的全部图题和表题，仅输出中文并保留编号，不使用 Markdown 表格或标题。
- 按用户要求翻译指定章节或部分。附件除标题、作者信息、参考文献及表格具体内容外均翻译。所有翻译均遵守第 3 节格式。

## 2. 特例

- **Scripta Materialia**：全文无子标题时，先用普通段落简述“引言、方法、结果与讨论、结论”的大概段落范围，再翻译全文。
- **npj Computational Materials**：按原文处理 Results、Discussion、Methods；正文开头至 Results 前视为无标题的引言，不说明段落范围。
- **International Journal of Plasticity**：保留 (Zhou et al., 2022) 等作者-年份引用格式。
- **综述类文章**（Review、Perspective、Tutorial、Progress Report、Roadmap、Systematic Review、Meta-analysis 等）：章节翻译固定设“摘要、引言、结论”3 个三级标题。没有结论章节时，以 Challenges、Outlook 或功能相近章节的原文标题及内容替代；若结论与这些章节并存，则分别设三级标题并全部翻译。

## 3. 翻译格式

- 固定术语：kink → 扭折；kink-pair → 扭折对；energy landscapes → 势能曲面；nucleation → 形核；edge dislocation → 刃位错；screw dislocation → 螺位错；kink bands → 扭折带。
- 中文与英文、中文与数字之间空一个空格。
- 行间公式用 $$ ... $$；行内公式和变量用 $...$；不用 \[ ... \] 或 \( ... \)。常见单个希腊字母用普通文本符号，如 α、β、γ。
- 晶面/晶向中的上划线负指数改为紧邻数字的 -，分数前缀改为普通文本，例如 \frac{1}{3}{10\overline{1}2} → 1/3{10-12}，各种 {10\bar{1}2} 写法 → {10-12}。保留原括号类型（{}、<>、[]、()），仅转换原文已有的分数前缀。
- 晶体学符号的括号与内部数字之间、数字之间及相邻括号之间均不空格，如 {10-11}、{10-11}<1-210>。
- 多层级有序或无序列表每级缩进 4 个空格。
- 加粗内容的末尾标点符号优先置于 `**` 之外，如 **关键词**：正文；若标点符号需加粗，则结束标记 `**` 后保留一个空格，如 **关键词：** 正文。

## 4. Markdown 输出结构

固定使用下列无编号二级标题：

    # 文献总结 - [论文中文标题] - [年份]

    ## 文献基本信息
    ## 论文内容详细总结
    ## 章节翻译
    ### 摘要
    ### 引言
    ### 方法
    ### 结论
    ## 结果与讨论章节子标题翻译
    ## 图表题翻译
    ## 指定章节翻译
    ## 附件内容翻译

- 文献基本信息直接以标签或段落列出，不设下级标题。
- 常规论文的章节翻译固定使用“摘要、引言、方法、结论”；综述类文章按第 2 节调整。
- 图表题翻译按图表编号连续列出，不设下级标题；仅在最后一个图题与第一个表题之间添加 ---，图题之间和表题之间不加分割线。
- 指定章节翻译和附件内容翻译仅在有相应任务时输出。
- 各二级内容块之间添加 ---，分割线前后各空一行。在章节翻译、指定章节翻译、附件内容翻译内，二级标题与紧随的第一个三级标题之间不加分割线；完成一个子标题的内容后，在下一个子标题前添加 ---。
- Scripta Materialia 的章节范围说明直接置于章节翻译开头，不设标题。
- 不输出 References/参考文献标题或内容。

## 5. 文件输出

- 保存到 2-summaries/文献总结_[论文中文标题]_[年份].md；方括号仅表示待替换字段，实际文件名不保留，并避免空格及非法字符。
- 后续指定部分或附件翻译追加到同一文件，不覆盖已有内容。
- 完成后给出 Markdown 文件路径。
